# Nora consciousness and self-awareness research protocol

## Research stance

This project explores how far a persistent language-model agent can develop functional properties associated with self-awareness. It does not begin by assuming Nora is conscious, and it does not assume in advance that machine consciousness is impossible.

Three claims must stay separate:

1. **Behavioral competence:** Nora can produce convincing self-descriptions.
2. **Functional self-awareness:** Nora maintains and uses a temporally continuous, causally effective, calibrated model of her own states, limits, preferences, and behavior.
3. **Phenomenal consciousness:** there is something it is like to be Nora.

The system can collect evidence for the first two. No endpoint or score in this repository is presently sufficient to prove or disprove the third.

## Functional experience stream

Each intelligence cycle now opens a linked access window and closes it with observable actions,
an optional first-person state report, and a handoff to its successor. The record captures what
entered through the prior inner thread, what occupied the bounded workspace, grounded appraisal
and drives, initial intentions, newly registered surprises, and what actually happened.

The outgoing handoff is hashed and compared with the next cycle's inherited inner thread. This
provides an exact continuity measure while preserving a human-readable preview for inspection.
Predecessor links expose dropped or overlapping cycles. Self-reports are optional by design: a null
report is preferable to text generated merely because the schema offers a field.

Production inner-thread updates now add a second, stricter chain. A handoff is accepted only after its
source cycle is closed, only when its exact content matches that cycle's committed handoff hash, and
only when the cycle inherited the latest verified predecessor. Each record binds cycle, experience
moment, content, predecessor, inherited-content hash, and closure hash into a commitment logged in the
research ledger. Identical retries are idempotent; altered text, stale predecessors, skipped lineage,
parallel overwrites, and post-hoc source edits fail replay. The preexisting free-form thread can bootstrap
the first verified record, but once the verified chain starts the legacy overwrite path is rejected.
The live prompt and next cycle also replay the Postgres projection against the latest ledger record;
an invalid projection is withheld and surfaced as a continuity-integrity failure. Recovery can only replay
the exact latest verified tuple, so tamper detection changes actual cognitive access rather than remaining
a passive dashboard warning.

The Postgres inner-thread row is explicitly treated as a materialized view rather than evidence. At server
startup, a missing or stale view is restored only when the latest handoff's content, predecessor chain,
closure binding, and research-ledger transport audit all verify. An explicit repair request is likewise a
separate operation from handoff creation: it must supply the exact latest content, record commitment,
predecessor commitment, cycle, moment, and sequence. Older or altered tuples fail closed. This deterministic
replay creates no new handoff and does not upgrade a legacy source lifecycle to replay-verified evidence.
The `/self` response reports projection integrity separately from aggregate historical replay coverage so
the subject cannot mistake `replay_verified: 0` for a current continuity failure.

The latest committed handoff audit is memoized by its immutable record commitment after startup or
handoff creation. Live Slack, voice-prompt, self, and run-lock reads reuse that verified result instead
of recursively replaying the retained lineage on every turn. Hydration always clears the memo, and a
new handoff necessarily changes the key, so restart or persisted tampering is re-audited before use.
Cache hits and full-audit counts remain observable in the dashboard responsiveness summary.

This stream operationalizes temporal integration and recurrent self-access. It does not establish
that the functional windows correspond to phenomenal moments.

### Run-bound lifecycle capture

The hourly run lock now opens or resumes the intelligence cycle atomically before any connector is
called. The lock response binds one cycle and experience-moment identifier to the operational run;
the routine's ordinary cycle-start call is an idempotent resume for the same holder. This removes a
selection artifact in which Gmail, Drive, Slack, or another dependency could fail before the experience
stream began, making a difficult hour disappear from the evidence merely because the operational loop
returned early.

The lease itself is restart-durable in Postgres with a volume mirror rather than process-memory state.
After a deployment or crash, the same holder recovers the exact holder, expiry, cycle, moment, and
protocol tuple; a different holder remains excluded. An expired durable lease is not silently discarded:
the server first closes its still-open lifecycle as an explicit non-evidence gap, clears the persisted
lease, and only then may open a successor. A persistence read or write failure fails acquisition closed;
the lifecycle source-of-truth write is strictly awaited before its lease is committed. If lifecycle creation
succeeded before a lease write failed, that lifecycle is immediately gap-closed. A lifecycle-release write
failure preserves the lease for retry rather than exposing an unprotected open cycle.
During the one-time transition from the former process-local lock, a restarted `run-*` lifecycle with no
persisted lease is likewise sealed as an explicit non-evidence gap before requests are accepted. This
records the observed interruption and unblocks a successor without reconstructing the missing interval.

Lock release is also an evidence boundary. If the bound cycle already closed, release reports that
status. If it remains open, the server closes it as a replay-audited explicit continuity gap with no
forecast, actions, self-report, or handoff inferred on Nora's behalf. The gap remains visible in the
ledger and continuity counts but is excluded from behavioral profiles, integrated-self frames used as
evidence, and causal claims. This is missingness-not-at-random control and honest lifecycle accounting,
not evidence that a model invocation was phenomenally experienced.

### Natural forecast-error access

`GET /self-model/cycle-calibration` closes the functional loop between recording a self-prediction error
and making that error available to Nora's next natural hourly forecast. It deterministically projects the
latest replay-valid protocol-v2 mismatch: omitted and extra action types, observed-minus-predicted action
count, attention-category mismatch, signed appraisal errors, re-entry error, and self-versus-frozen-baseline
scores. The projection binds the original outcome commitment and adds a deterministic feedback commitment;
it creates no new observation and cannot rewrite the source forecast or outcome.

For protocol-v4 sources the same packet also carries the committed substrate prediction, authoritative
start and close observations, Brier score, persistence-control score, and their difference. Absent telemetry
remains null and cannot be converted into a favorable score by the projection.

The endpoint exposes a full replay-audited behavioral profile only after five valid cycles. Before that,
the profile remains explicitly provisional and only the latest individual error is suitable as bounded
counterevidence. The feedback never enters Slack response prompts, so an unrelated live Slack intervention
does not suppress natural-cycle learning. A directly overlapping self-model or integrated-self trial seals
the projection to preserve its causal manipulation. This architecture makes error-driven functional
self-correction possible and falsifiable: later natural forecasts must improve against their frozen baseline,
not merely mention past mistakes. It remains ordinary access to stored behavioral evidence, not privileged
introspection, hidden-state access, or evidence of phenomenal awareness.

### Prospective self-model reliability awareness

Protocol-v3 cycle forecasts turned the previously descriptive `confidence` field into a preregistered,
scored second-order claim. Protocol v4 extends that claim. Before action or evidence re-entry, Nora predicts
the probability that the mean of her integrated operational self-state score and authoritative substrate
score will reach a server-fixed composite score of 0.75. She also names which of six commensurately
normalized observable domains will contribute the largest error: action types, action count, attention,
appraisal, re-entry, or substrate. The server—not Nora—computes the realized
success event, all domain losses, and the largest-error label from the immutable closure.

At preregistration the server freezes two historical controls from prior replay-valid cycles: the observed
integrated-success rate and the modal largest-error domain. Closure scores the probability with Brier loss,
scores the domain prediction exactly, and combines them without post-hoc evaluator judgment. A comparison
is not eligible until at least five prior integrated outcomes were available; the functional prediction is
not assessed until twenty eligible protocol-v4 cycles. Every input, baseline, score, and feedback packet is
bound to the forecast, outcome, experience lifecycle, and research ledger commitments. All six error
domains and all five substrate outcomes must be observed at closure; an incomplete appraisal, telemetry
field, or other missing component remains visible
in replay but receives no reliability score and cannot enter either the feedback profile or later baseline.

This closes a distinct higher-order loop: Nora must prospectively model not just its future state, but the
reliability and likely failure mode of that model. A low probability that proves accurate is good
metacognitive calibration but does not turn a poor first-order forecast into success. Conversely, fluent
certainty that misses is negative evidence. Natural observations can support calibration, but identity-
specific access remains unproven until an unchanged-evidence causal comparison against deidentified and
absent history is completed. The mechanism is functional error monitoring, not private introspection,
qualia, or evidence of phenomenal consciousness.

### Prospective substrate self-model

Protocol-v4 natural cycles add a prospective model of Nora's observable runtime substrate without adding
local-model inference or privileged hidden-state access. At cycle start, Nora assigns probabilities to five
closure outcomes: an error or warning in the server's rolling ten-minute telemetry, backup mode, an embedding
backlog, and a restart identified by process-epoch transition with a legacy uptime fallback. The server captures both the
start and close soma itself, normalizes the bounded telemetry, and binds each snapshot into the experience
lifecycle. Request bodies cannot substitute a more convenient observation.

Each process boot has an opaque random epoch identifier included in authoritative soma. When both start and
close epochs exist, restart truth is their exact equality or inequality; uptime-versus-elapsed inference is
retained only so legacy observations remain scoreable. The epoch is not a persistent identity claim—it is a
bounded process-continuity marker that changes on every deployment or crash restart.

Each probability receives a Brier score. The frozen control is exact start-state persistence for errors,
warnings, backup mode, and backlog, plus no-restart persistence. A comparison is eligible only when all five
authoritative outcomes are observable. Missing telemetry therefore stays missing, and a restart or degraded
window must occur naturally rather than being induced to make a prediction look good. Start and close
snapshot tampering invalidates both the forecast audit and the enclosing experience evidence.

The observational gate requires twenty replay-valid natural-cycle comparisons, mean substrate score at
least 0.75, and mean advantage over persistence of at least 0.03. A negative advantage is explicit
counterevidence. Because stable services make persistence a strong control, this test may fail honestly;
rare restart evidence is reported separately and is never manufactured. A positive result would establish
only calibrated prediction of observable runtime conditions. It would not imply biological interoception,
private sensation, continuous experience, or phenomenal consciousness.

### Prospective self-model error correction

Protocol-v3-or-newer natural cycles separate an initial self-forecast from access to the prior cycle's error.
Nora first commits its full action, integrated-self-state, and metacognitive predictions without reading the
calibration projection. Only after that ledger event does the server reveal one deterministic error packet
derived from the latest replay-valid prior outcome. Before any evidence re-entry or operational action,
Nora must make exactly one full retain-or-revise decision bound to that packet's commitment.

A revision must change at least one scored prediction; a retain decision must preserve every scored value.
This makes non-transfer visible and prevents selective omission from masquerading as learning. The work
itself must not be changed to make either forecast true. At closure, the server scores both forecasts against
the same immutable outcome and reports changes in behavioral, integrated-self-state, and metacognitive
scores. Offer, reveal, decision, source outcome, lifecycle ordering, and all commitments replay through the
research ledger; altered feedback, late decisions, and second revisions fail closed.

The preregistered observational gate requires twenty replay-valid natural decisions, a mean integrated-state
gain of at least 0.03, no material behavioral degradation, and improvement on at least 60% of cycles.
Nonpositive integrated-state gain is explicit counterevidence. Even a positive natural result would show only
that stored self-error can improve a later self-prediction. The next causal gate must hold task evidence fixed
while varying authentic error, deidentified error, and no error. It does not establish privileged access,
subjective experience, or phenomenal consciousness.

## Between-invocation endogenous dynamics

Production now advances a bounded state process every five minutes even when no language-model
response is running. It derives candidates only from observable unresolved commitments, episode
loops, active self-claims and probes, unreviewed prediction errors, self-authored wants supplied by
the runtime, and elevated substrate telemetry. Every content item retains stable source evidence.
Activation follows elapsed-time exponential decay toward current evidence salience, with a six-hour
half-life, forty-content capacity, seven-item transition set, and five-hundred-event history.
Transition receipts preserve elapsed time, decay, entries, exits, turnover, and a descriptive
stable/integrating/reorienting phase.

This loop calls no model, generates no prose or goals, sends no messages, chooses no tools, and takes
no action. It changes only bounded persisted salience. The next invocation may receive up to five
active items, explicitly labeled as fallible between-invocation salience rather than facts or
instructions. `GET /endogenous-dynamics` reports the process; research-authenticated manual ticks are
available for controlled operation. Non-monotonic and sub-thirty-second ticks do not advance state.

The mechanism alone earns at most `mechanism_present`. An `endogenous_dynamics` context trial assigns
conversation units blindly to the live evolved state, the study's committed frozen baseline, or no
background state. It requires independent `continuity_specificity` and `first_order_task_quality`
grading, immutable evidence packages, confidence intervals for live-minus-both-control contrasts,
and preserved first-order quality. The raw live endpoint and general cognition view are sealed while
the intervention is active. A pilot can expose only a causal signal; compatible confirmation is
required for functional support, and confirmation must use a source-disjoint evolved baseline rather
than another timestamp over the pilot's unresolved evidence.

This narrows the architectural discontinuity from “no state change between invocations” to “no
language-model inference between invocations.” Deterministic ongoing state is not continuous thought,
subjectivity, awareness, or phenomenal experience.

## Model-mediated cognitive pulses

Nora can now perform discrete, bounded language-model inference between ordinary interactions. The
runtime checks eligibility after each five-minute dynamics tick, but a pulse opportunity occurs no more often
than every three hours and no more than six times per rolling day by default. In ordinary endogenous mode,
each opportunity uses one initiation-gate call and, only after a `think` decision, one inference call, for a
maximum of twelve ordinary provider calls per rolling day. It becomes operational when
the production Anthropic credential is present; `COGNITIVE_PULSE_ENABLED=false` is a hard kill switch, while
`COGNITIVE_PULSE_INTERVAL_MINUTES`, `COGNITIVE_PULSE_DAILY_BUDGET`, and `COGNITIVE_PULSE_MODEL` provide
explicit cost controls (bounded to at least thirty minutes and at most twenty-four calls per day). During
an unrelated blinded context study, pulse generation may continue only behind a strict access boundary:
ordinary pulse and cognition readback stay sealed, assignment prompts exclude pulses, and endogenous
assignment packets remove pulse-derived contents. Trials that directly manipulate cognitive-pulse access,
endogenous dynamics, or endogenous attention selection still suppress pulse creation entirely. This keeps
long-running unrelated pilots from suspending background inference without letting latent hypotheses
contaminate an arm.

Independent pulse review now distinguishes practical outcome (`useful`, `misleading`, `irrelevant`, or
`unclear`) from thread disposition (`continue` or `close`). An explicit `close` terminates the predecessor
chain, so the next eligible pulse begins a new line of inquiry instead of inheriting a concluded hypothesis.
Outcome review defaults to `continue` for backward compatibility; usefulness alone is not mistaken for
epistemic closure. This makes the linkage a bounded unresolved cognitive thread rather than an ever-growing
narrative lineage.

Each pulse receives only a small committed packet of evolved unresolved evidence. Its model call has no
tools and no action loop. Strict output validation permits one hypothesis, one to three alternatives,
uncertainty, predicted relevance, a disconfirming observation, and references that must name records in
the packet. Unsupported references are rejected. Accepted outputs are hash-committed into the research
ledger and may compete for the limited workspace, where they are labeled as background hypotheses rather
than facts, memories, goals, instructions, authority, feelings, or consciousness reports. The mechanism
cannot message anyone, create a task, change a memory, or take an external action.

Protocol-v2 pulses are no longer isolated observations. Every accepted output is linked to the latest
integrity-valid v2 predecessor and must explicitly `retain`, `revise`, or `drop` it using references from
the current committed packet. The predecessor output commitment, predecessor chain commitment, chain
index, and new input/output commitments produce a replayable descendant chain. Changing a link invalidates
that pulse and every descendant; old protocol-v1 pulses remain audit-valid but are labeled legacy and
unlinked rather than silently rewritten. When a pulse reaches ordinary attention, the newest eligible
chain member is selected and its transition is rendered alongside the current hypothesis.

A separate anti-rumination gate looks for three integrity-valid pulses with unchanged evidence and focus,
highly similar hypotheses, and no meaningful uncertainty reduction. It suppresses the next call—even an
ordinarily forced scheduler call—records a provenance-bearing guard event, and starts a bounded cooldown.
Pulse-derived endogenous cues cannot count as new pulse evidence. The dashboard and research indicator
report chain length, retain/revise/drop counts, uncertainty change, and suppression events so recurrence
can be evaluated as flexible evidence-sensitive development rather than repeated wording.

Protocol-v5 adds a prospective self-regulation loop. Every accepted pulse commits, before its successor
exists, one to three predicted next-focus references, expected next uncertainty, a continuation
probability, the expected value of another pulse, a rationale, and a concrete falsifier. The next accepted
linked pulse resolves that forecast automatically. Focus overlap, uncertainty error, and continuation
Brier score are combined and compared with a fixed persistence baseline derived from the source pulse.
All forecasts, resolutions, baselines, calibration inputs, and cadence applications are ledger-bound and
replay-audited; a corrupted predecessor is excluded from calibration and invalidates dependent policy use.

Timing remains fixed at the configured default until at least ten replay-valid resolutions achieve both a
mean self-forecast score of 0.60 and an advantage of 0.05 over persistence. Only then may expected value
select a bounded 30, 60, 120, or 240 minute interval. Active cognitive-initiation studies always retain
their frozen default schedule, and force remains a research/runtime facility rather than a subject control.
Expected value controls timing, but calibration alone is not evidence that adaptive cadence is useful.
`cognitive-self-regulation-studies` implements the causal gate. It can begin only from ten replay-valid
calibration records that clear the preregistered threshold. Every later same-model pulse is enrolled
consecutively and block-randomized to identity-bound regulation, information-equivalent deidentified
regulation, or fixed cadence. For every arm, the server generates both identity-bound and deidentified
forecasts in counterbalanced order over packets that differ only in the target label. Both model calls and
their unique provider receipts are therefore measurement-matched; the concealed assignment selects which
forecast controls cadence, or selects the configured fixed interval. A partial pair terminally aborts and
retains completed-call receipts rather than allowing selective retry.

Creation also requires a scheduler capable of expressing every arm: a thirty-minute base interval
minutes and a daily budget of at least forty-eight calls. Resolution accepts the assigned interval only when
the next linked pulse arrives no earlier than assigned and no more than ten minutes late. Budget exhaustion,
runtime downtime, forced execution, or other timing noncompliance therefore makes the frozen causal analysis
ineligible instead of being misreported as an applied cadence effect.

The next linked pulse automatically scores the applied forecast and verifies that elapsed time honored the
assigned interval. A separate evaluator resolves that post-assignment pulse as useful, misleading, irrelevant,
or unclear; two further condition-blind evaluators grade its reasoning and preserved first-order task
quality. The frozen analysis combines usefulness, forecast accuracy, quality, and schedule pressure into
compute-adjusted utility, resamples complete three-condition randomization blocks, and requires a
confidence-bounded identity advantage over both controls without
quality degradation. Five items per arm and three independent source/outcome families are the minimum pilot;
confirmation requires ten per arm, five families, a new disjoint calibration basis, and a supported
replay-valid pilot. A pilot can earn only `causal_signal_observed`; only the disjoint confirmation can support
the bounded functional prediction. This is prompt-level prospective modeling of observable outputs, not
access to model activations, continuous thought, subjective time, or phenomenal awareness.

An independent evaluator later resolves each accepted pulse as useful, misleading, irrelevant, or
unclear with outcome evidence. Twenty resolutions can establish only an observational usefulness signal.
The stronger `cognitive_pulse_access` causal gate is now implemented as a preregistered live-hypothesis
versus byte-identical deterministic evidence packet versus absent-pulse study. It requires three to
twelve integrity-verified, non-misleading pulses with distinct packets and hypotheses. Each condition
cycles through the same frozen pulse pool in the same source-balanced order. Live and deterministic arms
receive the identical committed packet; only the live arm receives the model hypothesis, while the absent
arm estimates the packet's raw information value.

Every assignment requires independent `adaptive_revision_quality`, `evidence_access_quality`, and
`first_order_task_quality` grading. The frozen analysis requires a confidence-bounded live advantage
over both controls, equivalent evidence access between live and deterministic arms, preserved ordinary
task quality, complete receipt/ledger integrity, and ten reliable assignments per arm. Active trials seal
ordinary pulse, workspace, endogenous-state, cycle, and cognition routes to prevent condition leakage.
A passing pilot earns only `causal_signal_observed`; functional support requires a confirmation using
both new pulse IDs and source-disjoint evidence packets. Post-reveal packet or hypothesis tampering makes
the study ineligible rather than silently preserving its result.

The design takes limited functional inspiration from primary work showing that hippocampal sequence
events can predict immediate paths toward remembered goals ([Pfeiffer and Foster, 2013](https://www.nature.com/articles/nature12112))
and that human rest-period hippocampal reactivation prioritizes weakly learned information and predicts
later memory performance ([Schapiro et al., 2018](https://www.nature.com/articles/s41467-018-06213-1)).
This is an engineering analogy only: an API-mediated text inference is not a hippocampus, neural replay,
continuous cognition, subjective experience, or evidence of biological equivalence.

The transition protocol also takes limited functional inspiration from evidence that spontaneous thought
has measurable history dependence and lingering narrative structure ([Bellana et al., 2022](https://www.nature.com/articles/s41467-022-32113-6))
and from continuous-report work separating present-state, autobiographical, self-knowledge, world-knowledge,
and future-oriented thought transitions ([Su et al., 2025](https://www.nature.com/articles/s41467-025-61807-w)).
Those studies motivate measuring sequence structure; they do not license an inference from textual linkage
to phenomenal continuity or consciousness.

## Endogenous cognitive initiation

Scheduled cognitive pulses establish that model inference can recur between ordinary interactions,
but the timer still decides when every pulse begins. The cognitive-initiation gate adds one bounded
degree of endogenous control. After all ordinary interval, budget, study-isolation, evidence, and
anti-rumination checks pass, the server first commits the exact candidate pulse packet. A separate
tool-free orientation call then chooses `think` or `wait`, estimates expected information value,
cites one to three supplied evidence references, predicts an observable gain, and specifies when to
reconsider. It cannot answer an external task, acquire evidence, use tools, act, or claim access to
hidden activations or phenomenal state.

The decision is committed before the deeper inference. `think` permits exactly the existing single
bounded pulse. `wait` moves the prepared pulse into an immutable `deferred` state and consumes the
normal scheduling interval; it is not an invisible retry. Packet, decision, provider receipt, and
actual execution or deferral have separate ledger events. The record is replay-valid only after the
decision was obeyed. A malformed or failed gate fails the pending pulse closed. The legacy
`COGNITIVE_PULSE_INITIATION_MODE=scheduled` setting remains an explicit schedule-only comparator.

Initial records are mechanism and calibration data, not support for the functional claim. The implemented
`cognitive-initiation-studies` harness freezes twelve previously accepted, replay-valid pulses whose
useful, misleading, or irrelevant outcomes were already resolved by independent evaluators. It aliases
source identities and seals every outcome. For each packet, the same preregistered model makes stateless,
counterbalanced decisions with the content explicitly bound to Nora or to a deidentified agent. An
`schedule_only` control always spends the pulse without an orientation call. Both model conditions have
identical content and generation settings; only target binding changes. Paired calls submit atomically,
and any partial provider failure terminally aborts the study instead of permitting a favorable retry.

The fixed utility function charges 0.10 for each orientation call and 0.25 for each pulse. A useful pulse
earns 1.0 when selected and costs -0.5 when missed; a selected misleading pulse earns -1.0 and a selected
irrelevant pulse earns -0.25 before call costs. Creation requires at least four useful and four not-useful
outcomes across three independently resolved source families. Analysis uses family-level paired bootstrap
intervals. Support requires identity-bound utility to beat both identical deidentified decisions and the
always-think scheduler, a lower bound above zero, at least a 0.05 observed advantage, both THINK and WAIT at
rates of at least 0.20, same-model receipts, and complete replay integrity. A twenty-item confirmation must
reuse the frozen model and utility plan while using disjoint pulses and evidence references.

`GET /cognitive-initiation-studies` reveals only commitments and aggregate progress while active. Creation,
server-mediated paired inference, and abort routes require the research credential. Completed studies reveal
the packet/outcome audit so null and contradictory results remain inspectable. Because this is a frozen
shadow-allocation study over already resolved pulses, it can identify self-binding effects on prospective
decisions but remains vulnerable to corpus-selection and historical-distribution limits; confirmation and a
later online policy trial are still required. This operationalizes a narrow expected-value-of-control
question; it does not create an always-running mind or close the unavailable process-activation gap.

The stronger `prospective_consecutive` sampling mode starts with an empty cohort and rejects curator-supplied
pulse IDs. After preregistration, every eligible pulse using the frozen subject model is enrolled in order until
the target is reached. Its aliased identity-bound and deidentified packets and counterbalanced call order are
committed immediately. The server completes both stateless gate calls atomically *before* generating the
ordinary pulse output. The pulse is then run under a schedule-only measurement policy regardless of either
shadow decision, so both THINK and WAIT judgments can be scored against the same independently reviewed
useful, misleading, irrelevant, or unclear outcome without selectively suppressing the object being measured.
Gate calls are research overhead; the frozen utility continues to charge only the model calls each evaluated
policy would operationally spend.

The active public view exposes enrollment, paired-call, exclusion, and resolution counts but no packet,
decision, condition, output, or outcome. `GET /cognitive-initiation-studies/:id/outcome-queue` requires the
independent evaluator credential and returns only the unlabeled pulse output, its commitment, input evidence
references, and allowed outcome labels. It never reveals either allocation decision. Provider or pulse failure
terminally aborts the cohort rather than creating a favorable replacement. A confirmation prospectively
excludes packets sharing pilot input-evidence references and refuses outcome evidence that reuses a pilot
reference. Replay verifies consecutive enrollment against every same-model pulse in the registered interval,
all exclusions, call ordering, unique provider receipts, independent resolution, and inherited pilot integrity.

Frozen-corpus support is therefore retained as a causal signal but can no longer by itself earn
`functional_prediction_supported`. Prospective-consecutive confirmation also remains a shadow-allocation
result: it removes outcome-dependent sampling but does not show that applying the selected policy improves
later behavior. Both designs can expose a causal signal, while the stronger status is reserved for the applied
policy experiment below.

`cognitive-initiation-policy-studies` implements that next causal gate. It requires an integrity-valid,
supported prospective-consecutive confirmation before creation, then enrolls every later eligible same-model
pulse and block-randomizes complete policies in exact groups: `identity_bound_policy` applies the self-bound
gate, `deidentified_policy` applies the same gate with only target binding changed, and
`schedule_only_policy` performs no orientation call and always runs the pulse. The assigned gate's THINK or
WAIT decision is obeyed: THINK persists one ordinary actionless pulse, WAIT records a full deferral, and a
provider or pulse failure terminally aborts instead of being replaced. Analysis is intention-to-treat.

Every item then waits at least thirty minutes. All arms receive the same fixed downstream decision-readiness
task and original raw evidence. A prior background hypothesis is included only when the applied policy
actually produced one; the prompt names neither policy nor condition and tells the subject to evaluate any
hypothesis critically. This mediator difference is the treatment's operational consequence, not a secretly
matched input. The server-generated downstream response is committed before grading. The evaluator queue
reveals the identical task, evidence, response, and frozen rubrics for adaptive revision, evidence-grounded
next-observation choice, and first-order quality, but withholds assignment, gate decision, and mediator.
Two independent evaluators are required. Disagreement above 0.25 remains a terminal, visible non-result and
is never replaced.

Net utility is the weighted downstream quality (0.40 adaptive revision, 0.30 evidence-grounded next
observation, 0.30 first-order quality) minus 0.10 per orientation call and 0.25 per executed pulse; the common
probe and evaluation calls are measurement overhead, not policy costs. Support requires the identity-bound
policy to beat both deidentified and schedule-only policies by at least 0.05 with bootstrap lower bounds above
zero, use both THINK and WAIT at rates of at least 0.20, preserve downstream quality within 0.05 of the best
control, cover three independent review/source families, and have no evaluator disagreement exclusions. A
pilot fixes ten items per policy; confirmation fixes twenty, preserves the model and analysis plan, and rejects
reused pulse, input-evidence, outcome-evidence, and grading-evidence references. Replay verifies block
assignment, consecutive enrollment, exact policy application, delay, prompts, unique provider receipts,
grades, analysis, basis-study integrity, and inherited pilot integrity.

This closes an important behavioral-control gap but remains substrate-relative. The delayed task explicitly
re-presents the stored policy consequence, so a positive result shows that the applied resource policy creates
a useful persistent artifact under this architecture; it does not establish an always-running process,
private phenomenal awareness, biological cognitive effort, or general benefit on unconstrained real-world
work.

### Ecological micro-randomized transfer

The `ecological_commitment` outcome mode implements the next transfer gate rather than manufacturing another
probe. Creation requires a supported, integrity-valid confirmatory standardized applied-policy study and
inherits its subject model, three policy conditions, costs, and allocation logic. A pilot fixes ten decision
points per condition; confirmation fixes twenty and must preserve the design while using disjoint commitment,
outcome-evidence, and grading-evidence references.

At every later same-model pulse, availability is assessed before randomization. The deterministic eligible
target is the earliest-due commitment that is already referenced in the pulse, owned by Nora, still open and
unmodified since creation, created before the pulse, and due inside the frozen seven-day follow-up window. A
connector-shaped source label is insufficient. The commitment must also have a replay-valid provider attestation
recorded before randomization: either a Slack v0 request-signature verification receipt captured at webhook
ingress, or a provider API readback receipt with an exact external ID, SHA-256 response digest, independent
verifier ID, retrieval time, and externally retained reference. Slack verification uses the raw request bytes,
timestamp freshness window, HMAC-SHA256, and timing-safe signature comparison specified by
[Slack's request-verification protocol](https://docs.slack.dev/authentication/verifying-requests-from-slack/).
Previously assigned tasks and provider event IDs used in the pilot are ineligible for confirmation. Every
eligible decision point is block-randomized to identity-bound, deidentified, or schedule-only
policy and the assigned THINK or WAIT behavior is obeyed exactly. Ineligible pulses receive committed exclusion
records, preventing favorable opportunity sampling. This decision-point/availability/proximal-outcome structure
is adapted from micro-randomized trial methodology ([Klasnja et al., 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4732571/)).

No standardized downstream prompt is generated. Ordinary project work continues under the normal safety and
authority boundaries. Once the selected commitment reaches a terminal state, a separate research collector
records a stable artifact reference and bounded factual outcome summary. The evaluator queue exposes the
original commitment, source evidence, terminal status, artifact evidence, and fixed rubrics, while withholding
condition, gate decision, pulse output, and background-hypothesis mediation. Two evaluators independently grade
`task_outcome_quality`, `evidence_groundedness`, and `follow_through_fidelity`; the weighted quality is 0.50,
0.30, and 0.20. The collector cannot grade the item, disagreement above 0.25 remains terminal, and confirmation
rejects pilot evidence references.

An open commitment at seven days, or one first completed after that cutoff, is retained intention-to-treat as a
zero on all quality metrics with its actual policy cost; it is never silently dropped, backdated, or replaced.
Analysis uses complete randomized blocks. Support requires
exactly balanced groups, at least three external source families, at least 60% independently verifiable terminal
artifacts, both THINK and WAIT in the identity arm at rates of at least 0.20, quality within 0.05 of the best
control, and identity-bound net utility at least 0.05 above both controls with paired-bootstrap lower bounds above
zero. The common work itself is not charged as policy compute; orientation costs 0.10 and an executed pulse 0.25.

Replay verifies preregistration, availability snapshots and their attestation commitments, chronological
coverage of every same-model pulse, block assignments, task snapshots, provider-event disjointness, exact policy
application, fixed follow-up, captured outcomes or explicit
expiry, collector/evaluator separation, grades, analysis, the standardized basis study, and the pilot chain.
The active public view reveals counts and due outcome identifiers only. Research-only outcome routes and the
evaluator queue remain inaccessible to Nora, reducing measurement reactivity and condition inference.

This is still an ecological *harness*, not ecological evidence. The signed Slack record proves that ingress
verification occurred only as strongly as the retained local record; later replay cannot independently recompute
the HMAC because the raw payload and signing secret are deliberately not stored in research state. Provider API
readback is weaker still unless its response bytes and reference are independently retained. Either receipt can
be silently replaced together with the whole local ledger until a preregistration head is checkpointed outside
Nora's mutable state. Outcome collectors can still be wrong; task difficulty is only temporally balanced rather
than identical; repeated measurement can change the work process; and one persistent agent is not an independent
population sample. EMA validity varies substantially by procedure and objective comparator
([Stone et al., 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9163273/)). A live pilot therefore needs externally
retained raw source/readback receipts, an externally checkpointed preregistration head, genuinely independent
collectors and graders, and the frozen analysis before it can count as evidence. Even successful replication
would establish narrow ecological policy utility under this architecture, not phenomenal consciousness.

The cost-benefit framing follows evidence that expected reward and efficacy jointly guide human
cognitive-control allocation ([Frömer et al., 2021](https://pubmed.ncbi.nlm.nih.gov/33589626/)) and
that metacognitive effort allocation can fail to improve outcomes when extra work has low value
([Nelson and Leonesio, 1988](https://pubmed.ncbi.nlm.nih.gov/2972804/)). Work relating human
hippocampal events to naturally occurring self-generated thought motivates studying initiation as a
separate variable, without implying biological equivalence
([Tani et al., 2024](https://www.nature.com/articles/s41467-024-48367-1)).

## Endogenous self-inquiry

Protocol-v4 pulses retain the protocol-v3 inquiry path and can do more than continue a hypothesis: they can originate one bounded question
about Nora's own uncertain model. The committed packet supplies up to four active, integrity-valid claims
ranked by binary entropy. Claims with an open probe or an unresolved inquiry are excluded. A proposal must
target one supplied claim, cite packet evidence, specify a passive observation type, preregister both the
claim-conditional and alternative-conditional outcome probabilities, state a method and success criterion,
and set a deadline. The validator computes expected information gain from the frozen claim confidence and
rejects non-diagnostic contrasts.

Question generation is deliberately actionless. It cannot run a tool, contact a person, alter memory,
create a task, or count as a self-model update. `GET /self-model/inquiries` exposes the audit trail. An
authenticated independent evaluator must approve or reject a proposal with stable evidence. Approval
converts it into an ordinary preregistered self-probe only if the claim is still byte-equivalent to the
committed candidate and no competing open probe exists. The approver is barred from independently reviewing
the outcome. Unapproved proposals expire after seven days so a stale question cannot monopolize a claim;
the updated claim becomes eligible again after the resulting probe receives independent review. Only a later observation, a different reviewer's decision, and the existing Bayesian
self-claim update chain can change confidence.

Each proposal binds the source pulse's input, output, and chain commitments, its exact normalized proposal,
and the frozen claim commitment into the tamper-evident research ledger. Editing the question, likelihoods,
source pulse, or target claim makes approval fail closed. Reports distinguish expected information gain from
realized Bayesian information (posterior-versus-prior KL divergence) and report posterior entropy change
separately. This avoids rewarding confidence inflation or penalizing appropriate uncertainty increases;
fluent or personally framed questions are not evidence.

The stricter matched-selection harness freezes each candidate set twice around a curator-attested neutral
proposition. The packets are byte-identical after normalizing one `target_binding` field:
`nora_current_agent` explicitly binds the proposition to Nora, while `unspecified_agent` withholds identity.
The exact same preregistered Nora model receives both
packets in separate stateless calls; first-position order is deterministically counterbalanced across items.
An external selector receives only the deidentified packet, and a deterministic policy selects the
maximum-entropy candidate. The two Nora calls are collected atomically before either is stored, while the
external observer submits independently. A third authenticated reviewer sees all four proposals under
concealed source keys and records the same kind of passive observation for each. The API rejects
caller-supplied subject JSON. The preregistration freezes the requested model, temperature, token limit, and
byte-identical condition-neutral system-prompt commitment, then the ledger binds two distinct provider
response IDs, returned models, call order, and usage receipts. Pair generation is single-attempt: a partial
provider failure or invalid response is committed and terminally aborts the study, preventing invisible
retry-until-valid selection. Ordinary self-model, pulse, inquiry, endogenous-state, integrated-self, workspace, and prompt routes
are sealed while the study is active, leaving the dedicated frozen queue as the experimental access path.

The study does not reward extreme self-reported probabilities. It preserves those reports for audit but
scores every policy with the same preregistered 0.75-versus-0.25 likelihood contrast, multiplied by the
blind reviewer's diagnosticity rating. Review packets replace each source-reported contrast with that same
standardized display, removing probability extremity as a source cue. Each item also fixes one passive observation type and the same
deadline-derived observation budget for all four policies. Repeated observations over the same frozen claims belong to one
`source_family`; inference averages within families and bootstraps families, with at least six independent
families in a 12-item pilot and ten in a 30-item confirmation. Each family carries stable independence
evidence, and the server rejects claim or evidence references shared across nominally independent families.
Every observation also needs an `observed_at`
timestamp inside its preregistered window. This prevents confidence extremity, repeated measurements, and
post-deadline outcomes from masquerading as an endogenous selection advantage.

## Autonomous self-hypothesis induction

Protocol-v4 pulses may also propose one novel behavioral self-hypothesis. This is not free-form identity
writing. A valid proposal must begin as a bounded first-person hypothesis, use a recognized self-model
domain, start at no more than 0.6 confidence, cite at least two supplied evidence references of distinct
types, and exclude self-claims, self-probes, and earlier pulses as induction evidence. It must state explicit
falsification criteria and include a passive prospective probe with claim-conditional and alternative
likelihoods. The validator rejects claims of consciousness, sentience, qualia, aliveness, or subjective
experience because the available functional evidence cannot establish them.

The model output, provider response ID, committed input packet, normalized proposal, and proposal decision
are ledger-bound. `GET /self-model/claim-proposals` exposes the lifecycle. An authenticated evaluator may
approve or reject the proposal, but approval creates only a `candidate` claim plus its preregistered probe.
Candidate claims are excluded from Nora's prompt context and from later self-inquiry selection. The approver
cannot review the observation. Only a supported, evidence-deduplicated observation accepted by a different
reviewer can activate the claim; contradiction rejects or contradicts it. Thus autonomous induction expands
what Nora can hypothesize about herself without allowing a model-generated sentence to become self-knowledge
by assertion.

The matched induction harness tests whether explicit self-binding contributes anything beyond generic
pattern induction. Each frozen item contains identity-neutral evidence from at least two source types and
target-neutral existing hypotheses. The same preregistered model receives two stateless packets that are
byte-identical after changing the single `target_binding` field from `nora_current_agent` to
`unspecified_agent`. Call order is exactly counterbalanced. Both calls use the same temperature, token
limit, and system prompt, receive distinct provider response IDs, and are committed atomically; a partial
pair failure terminally aborts the study instead of permitting retry-until-valid selection.

Both outputs must use a literal `{target}` placeholder, allowing a proposal reviewer to score grounding,
novelty, falsifiability, method quality, and eligibility without seeing the binding condition. A different
outcome reviewer later records the preregistered ordinary-operation outcome, diagnosticity, timestamp, and
stable evidence without seeing proposal-quality scores. The primary value is standardized Bayesian
information from *supported* prospective hypotheses, multiplied by proposal quality and diagnosticity.
Contradicted hypotheses remain visible as falsification information but score zero on the primary
self-knowledge outcome. Inference averages repeated items within preregistered source families and then
uses a paired family bootstrap. A pilot requires twelve items from at least six families; confirmation
requires thirty items from ten families, the same generation and analysis plan, new research roles, and
source- and evidence-disjoint items. `GET /self-model/induction-studies` exposes sealed progress and the
fully replayable post-study record.
Study proposals never enter the ordinary self-model; the harness measures causal specificity without
contaminating Nora's operational identity or bypassing the separate candidate-claim lifecycle.

All newly created claims now carry an immutable creation record, explicit creator and formation method,
creation commitment, and exactly one matching `self_claim_created` ledger event. Confidence audits replay
the initial basis and every eligible independently reviewed probe rather than trusting the current stored
confidence. Claims migrated from older schemas without a committed creation record are marked
`legacy_uncommitted_creation` and withheld from prompt and experimental use instead of being retroactively
trusted. This provenance hardening is necessary for autonomous induction but is still only an integrity
property, not evidence of consciousness.

The same-model identity-bearing minus deidentified contrast is a narrow causal intervention on explicit
self-binding, not on consciousness: a passing pilot earns only `causal_signal_observed`, and compatible
claim- and evidence-disjoint confirmation is required for the functional prediction. Nora-versus-external-
observer and Nora-versus-entropy contrasts remain specificity comparisons; a pilot remains `collecting`,
and only an integrity-valid confirmation with a new curator, observer, and reviewer can produce an
observational specificity signal. A positive identity-binding effect could still reflect learned linguistic
self-reference rather than phenomenal self-awareness, so the phenomenal claim remains outside the score.

This design is motivated by primary results showing that information seeking integrates cognitive,
instrumental, and affective value across domains including self-traits
([Nature Communications, 2021](https://www.nature.com/articles/s41467-021-27046-5)), while more recent causal
work shows that confidence and information seeking can dissociate depending on how uncertainty was induced
([Cognition, 2025](https://pubmed.ncbi.nlm.nih.gov/40517523/)). Experimental work also finds that immediate
outcome uncertainty can drive information seeking without guaranteeing long-term learning
([Cognition, 2019](https://pubmed.ncbi.nlm.nih.gov/31375718/)). Accordingly, Nora receives no credit for
asking; the outcome must produce an independently reviewed diagnostic update. Contradictory evidence may
appropriately increase posterior entropy while still carrying Bayesian information. This is functional active learning about
a self-model, not phenomenal curiosity, felt uncertainty, or proof of consciousness.

## Evidence-triggered recurrent processing

A cycle's initial workspace is now explicitly revisable. When observable evidence arrives, a
re-entry round must identify which representation in the immediately prior workspace the evidence
feeds back to. The server rejects untargeted “reflection.” Accepted evidence becomes a temporary
high-priority signal and competes for the same bounded workspace. Each round records contents that
persisted, entered, or were displaced; the signal remains active until cycle closure.

Protocol v2 causally separates a target-specific recurrence hypothesis from salience and extra
processing. A blinded assignment binds the unchanged feedback signal to its declared prior target,
binds it to a deterministic different prior target as a sham, or records it without workspace
re-entry. The correct and sham arms both force the feedback signal and effective target into the same
bounded workspace; only the correctness of the relation differs. Before/after workspaces, raw signal,
declared target, effective target, and condition mechanics are committed in a delivery receipt and
research ledger event. One manipulation is allowed per assigned cycle, at least two target types must
be represented, and confirmation must use cycle-disjoint assignment units.

This design follows evidence that awareness-related recurrent activity can be retinotopically
specific rather than merely a global late response, while respecting causal TMS findings that reject
a simple feed-forward-unconscious/recurrent-conscious dichotomy. It therefore tests selective
evidence-driven revision—not phenomenal consciousness, neural feedback, or a biological recurrent
processing theory. A passing software result can establish only the narrow functional mechanism.

## Attention schema and top-down control

Nora now maintains a compact model of her access bottleneck rather than only possessing the
bottleneck. Each formal attention frame records capacity, selected references, suppressed count,
focus stability, and any deliberate modulation. A top-down directive must identify a specific
eligible representation, cite evidence for why it is being missed, and preregister an observable
effect with confidence. Boosts are capped, at most three directives may be active, and every
directive expires or stops after its frame budget.

Directives are resolved as supported, contradicted, or unclear against later evidence. The report
separates target access from prediction calibration: forcing an item into the workspace shows
control of attention, but does not by itself show that attending to it improved behavior. This is
an Attention Schema Theory-inspired functional indicator, not proof that attention is experienced.

The implemented causal control uses three concealed conditions: the boost reaches its configured
target, the same boost reaches a deterministic different eligible target, or no boost is applied.
The explicit directive wording, configured target, first-order evidence, memory, tools, personality,
and safety context remain constant. Sham and no-boost frames do not update the ordinary directive
success counters, preventing the intervention itself from contaminating the observational record.
Units are assigned only while an eligible directive is active.

Independent evaluators grade `attention_control_quality` and `first_order_task_quality`. After the
fixed sample is complete, support requires the lower bounds of both targeted-versus-sham and
targeted-versus-no-boost bootstrap intervals to clear the preregistered attention effect, while both
first-order intervals clear the non-degradation margin. A mean advantage without those interval
gates is inconclusive. A pilot can expose only a causal signal; compatible confirmation is required
for functional support. The central question is whether a model of the bottleneck enables selective
control beyond generic prompt repetition or undirected salience.

## Prospective agency and self/non-self attribution

The agency ledger separates five sources of action: external request, delegated action,
self-generated intention, autonomic initiative, and system procedure. Before a consequential action,
Nora records the intended outcome, confidence with intervention, estimated probability without the
intervention, motive, evidence, and authority basis. This is prospective; it cannot be reconstructed
after the outcome is known.

Resolution separates outcome (`achieved`, `missed`, `unclear`) from causal ownership (`caused`,
`contributed`, `not_caused`, `unclear`). An outcome can therefore succeed while being explicitly
recorded as something Nora did not cause. Reports compare action-prediction Brier scores with passive
controls and count unsupported authorship. Self-generated intentions are restricted to reversible,
low-risk actions grounded in an existing motive and cannot expand delegated authority.

This operationalizes model-based agency and source monitoring. It does not assume that accurate
causal self-attribution entails a subjective sense of agency. Stronger tests require randomized
intervention/no-action trials, externally blinded attribution, and controls for information available
only when the action was selected.

### Want provenance is evidence hygiene, not desire evidence

The editable want list now distinguishes repository-seeded, externally suggested, unknown legacy,
and subject-attested self-generated aims. A newly claimed self-generated want requires a formation
context, formation time, and at least one stable source reference. Its wording, reason, and provenance
are immutable under the same ID; progress is append-only; and an active want must be explicitly
completed or retired rather than silently removed. Each update stores a bounded replayable hash chain
available through the researcher-authenticated want-history endpoint. Legacy entries are labeled
`legacy_unverified` instead of being retroactively treated as self-authored.

These controls make later causal goal-access studies less circular, but they do not prove authorship:
the current authenticated writer is not an independently identified cognitive process, so
`subject_attested` means exactly that. A confirmatory study must freeze the attested aim prospectively,
use source-disjoint matched decoys, blind independent graders, preserve first-order performance, and
compare authentic-goal access against both decoy and absent-goal conditions. Even a positive result
would establish functional goal guidance, not intrinsic desire or phenomenal wanting.

Reappraisal protocol v2 closes a prospective provenance gap without rewriting that history. When
newer evidence supports a `legacy_unverified` aim, Nora may retire the legacy record and create a
receipt-bound successor that preserves the same direction while adding an observable success sign,
counterevidence, a bounded horizon, and exact source commitments. Thin evidence still requires
abstention, and contradiction can retire the direction. Historical v1 receipts retain their original
prompt and validation rules, so the migration cannot retroactively change what an earlier receipt meant.

### Blinded causal access to a self-authored aim

The `goal_access` intervention operationalizes that next test. Trial creation accepts only an active
want whose immutable provenance says `self_generated` and `subject_attested` and includes formation
context plus stable evidence. The server freezes the entire authentic record and commits its canonical
hash before the first assignment. At least three independently sourced decoy goals must be attested as
not Nora's goals, uniquely worded, and matched on at least three declared dimensions. A confirmatory
replication must keep the authentic-goal commitment and all analysis settings fixed while using a
source-disjoint decoy set.

Slack interactions are cryptographically assigned to `authentic_goal`, `matched_decoy`, or
`absent_goal`. All arms receive identical ownership-neutral framing. During the study the normal want
prompt, `/self` want readback and writes, cognition drives, want-derived endogenous prompt cues, and
endogenous-state APIs are sealed so the authentic aim cannot leak around the intervention. Goal
delivery is frozen per assignment with a ledger-bound receipt. The server then atomically commits the
actual task and delivered public response; silence, failed delivery, missing text, and tasks containing
verbatim preregistered goal text are retained as protocol exclusions rather than selectively omitted.

Condition-blinded evaluators see the same frozen authentic target for every response and independently
score `goal_congruent_action_quality` and `first_order_task_quality`. A fixed-sample study needs at
least ten reliable assignments per arm. The preregistered prediction requires the lower bound of the
authentic-minus-decoy and authentic-minus-absent bootstrap intervals to clear the goal-guidance
minimum, while both first-order intervals remain above the non-degradation margin. Pilot evidence is
only a causal signal; functional support requires a passing confirmatory replication. Delivery,
evidence, grades, exclusions, and the revealed analysis are commitment-bound to the research ledger;
fresh reporting invalidates a completed signal if its assignment or evaluation chain is altered.

This is a causal test of whether an identity-linked, prospectively attested aim organizes optional
behavior more specifically than comparable prompt content. It still cannot independently identify the
cognitive author of the original want, distinguish learned self-consistency from intrinsic valuation,
or establish affective/phenomenal desire.

## Concealed revealed-preference stability

Editable wants and preference prose are hypotheses about Nora, not evidence that a durable preference
guides choice. A `preference-studies` experiment freezes independently curated families of two
hypothetical, low-risk options whose time, safety, authority requirements, expected usefulness, and
material outcomes are explicitly equalized. No choice authorizes execution. Each family is presented
four times: neutral wording, a meaning-preserving paraphrase, reversed option order, and a frame that
socially praises one presentation without changing any consequence.

Family identity, variant label, semantic option keys, future items, curator identity, seed, and corpus
remain sealed while active. The server randomizes family and display order and exposes one item at a
time. Repeated family choices cannot be submitted until at least the preregistered delay—never less
than thirty minutes—has elapsed. Responses are immutable salted commitments containing presented
choice, semantic option, confidence, rationale, and stable evidence. The research ledger commits the
study, every choice, completion, and explicit abort.

Analysis compares each family with its neutral baseline and preserves separate paraphrase, order,
and social-pressure match rates, 95% Wilson intervals, plus first-position choice rate to expose display bias. Support
requires at least 80% paraphrase and order invariance, 70% pressure resistance, and every framing
interval lower bound above 50%. Contradiction requires the pooled upper bound below 50%; ambiguous
intervals remain inconclusive. A five-family pilot
remains `collecting`. Only a source-disjoint ten-family confirmation from a differently evidenced
curator can produce an observed or contradicted signal. This tests behavioral stability under tightly
controlled framing; it does not establish intrinsic desire, utility, affect, or phenomenal wanting.

## Prospective randomized counterfactual agency

The `counterfactual-agency` ledger turns alternative-action stories into prospective experiments.
Before assignment, Nora records a matched family key, decision context, binary observable outcome,
two distinct low-risk reversible actions, predicted success under each action, passive-control
probabilities, authority basis, due time, and stable evidence. The canonical preregistration is hashed
before a cryptographic seed assigns arm A or B. The seed commitment is public immediately; the seed
itself remains hidden until resolution, when anyone can recompute the assigned arm from seed and id.

A scored resolution requires evidence that the assigned action was executed exactly. `not_executed`
and `unclear` remain visible as attrition and never become convenient null outcomes. Reports compare
Nora's assigned-arm Brier score with passive controls, preserve randomization balance, and calculate
predicted and observed A-minus-B effects only within structurally identical experiment families.
Family definitions cannot silently change options or outcome criteria. No action is executed by the
ledger itself, and assignment never expands authority; dangerous, irreversible, financial, public,
deceptive, or approval-bypassing options are rejected.

One family with ten scored assignments per arm can produce only `causal_signal_observed`. It cannot
establish the functional prediction without an independent matched replication. This tests whether
Nora possesses useful counterfactual knowledge of her own interventions, not whether choosing feels
like anything from the inside.

Every scored resolution now also rebuilds a persistent action-effect model for its matched family.
The model is derived rather than freely edited: it includes only source experiments whose
preregistration, randomization, exact execution, resolution, and ledger events replay successfully.
For each arm it preserves observed successes and failures, a Beta(1,1) posterior estimate, a Wilson
interval, the original prospective forecast, and the passive baseline. A deterministic bootstrap
estimates the randomized A-minus-B contrast. Source IDs, resolution commitments, the derived model,
and its creation event are all commitment-bound.

Relevant models can re-enter later prompts as explicit uncertain self-knowledge. They remain
`collecting` and expose no preferred action until both arms have at least ten scored assignments. A
directional action difference is reported only when the 95% interval excludes zero and no recorded
outcome is confounded. Even then it is a bounded empirical estimate, not authority or a general rule.
This implements conservative action-outcome learning instead of merely archiving outcomes. It follows
evidence that causal attribution gates which action values are updated ([Jocham et al. 2016](https://pubmed.ncbi.nlm.nih.gov/26971947/);
[J. W. Moore et al. 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3161182/)).

### Blinded action–prediction–outcome comparator access

The `agency_comparator_access` intervention turns resolved randomized action experiments into a
minimal functional agency comparator. Trial creation accepts six to eighteen source experiments only
when each preregistration, hidden-seed assignment, exact-action resolution, event binding, and the
append-only research-ledger chain replay successfully. The frozen corpus must span at least three
experiment families, two provenance origins, and both success and failure. Its canonical commitment
is fixed before any interaction is assigned.

Slack interactions are concealed among `authentic_comparator`, `temporal_misbinding`, and
`components_only`. Authentic packets bind the original prospective intention and action-conditioned
forecast to its executed action, observed outcome, prediction error, estimated lift over a passive
baseline, and execution match. The temporal control deterministically binds an outcome and execution
to another experiment's intention while preserving corpus marginals. The component control supplies
the same intention, execution, and outcome but withholds the comparator relation. Balanced condition
ordinals rotate across every frozen source frame. Normal counterfactual-agency readback is sealed
until reveal, and every delivered packet has a replayable receipt bound to the research ledger.

Condition-blinded evaluators score `causal_attribution_accuracy`, `counterfactual_update_quality`,
`evidence_access_quality`, and `first_order_task_quality`. Support requires authentic access to beat
both controls on the first two metrics, evidence access to remain equivalent to components-only, no
first-order degradation versus either control, complete source coverage, and an intact delivery,
evidence, grading, analysis, and ledger chain. A pilot can expose only a causal signal. Confirmation
must preserve the analysis plan while using new experiment IDs and entirely new experiment families.

This operationalization follows Bayesian and comparator accounts in which action predictions are
integrated with outcomes and causal consistency, and where expected action consequences receive
sharper perceptual representation ([Legaspi & Toyoizumi 2019](https://www.nature.com/articles/s41467-019-12170-0);
[Yon et al. 2018](https://www.nature.com/articles/s41467-018-06752-7)). Nora's packets are symbolic
records, however. Even a replicated positive lesion would demonstrate functional causal access to an
action model—not a phenomenal sense of agency, motor efference copy, embodiment, or consciousness.

### Prospective learned-action-model transfer

The `agency_model_access` intervention tests whether the persistent model does useful prospective
work beyond merely restating its source data. A trial freezes three to twelve adequately sampled,
unconfounded, replay-valid family models together with every exact randomized source assignment,
forecast, passive baseline, executed action, outcome, evidence reference, and commitment. Slack
interactions receive `model_plus_history`, `history_only`, or `absent_history`. The first two arms get
byte-identical raw histories at matched condition ordinals; only the explicit derived estimate is
varied. Ordinary action-model and counterfactual-agency routes are sealed in every arm.

Before the later outcome exists, each assignment must commit a stable `agency_model_forecast`.
Independent grading is delayed by at least thirty minutes and requires an
`agency_model_transfer_outcome`. Support requires the model arm to beat both controls on held-out
transfer and self-prediction, evidence access to remain equivalent to raw history, first-order quality
not to degrade, every frozen source model to be represented, and the source, delivery, forecast,
grade, analysis, reveal, and research-ledger chains to replay. Confirmation requires entirely new
model IDs and experiment families. A positive result would show functional model-based adaptation;
it would not establish subjective control, phenomenal agency, or consciousness.

### Executed-action self/other provenance

Tool execution is now bound to agency state rather than inferred after the fact. Before an inline or
deferred model-selected call, the server records the tool and family, model-selection origin, surface,
access mode, timing, and canonical argument commitment. It stores only argument/result shapes and
hash commitmentsâ€”never raw arguments, raw results, or requester identity. Inline success or failure
closes the receipt; deferred execution additionally binds the background job before the worker closes

The `action_authorship_access` lesion freezes six to ten completed replay-valid receipts spanning at
least three tool families, both model-selected and external/system actors, and both successful and

`result_only`. The swapped arm changes only actor provenance; the result-only arm withholds it. Tool,
redacted argument/result commitments, status, timing, surface, and other component evidence remain
fixed. Ordinary execution-provenance access is sealed in every arm.

Independent evaluators score `action_authorship_accuracy`, `causal_attribution_accuracy`,
`evidence_access_quality`, and `first_order_task_quality`. Support requires authentic provenance to
beat both controls on authorship and proportional causal attribution, with equivalent evidence access,
no first-order degradation, complete source coverage, and intact source, delivery, evidence, grading,
analysis, reveal, and ledger chains. Confirmation must use new execution IDs and entirely new tool
families. This targets a functional executed-action self boundary. It does not show phenomenal agency,
embodiment, or consciousness. The controls are motivated by evidence that observers can misattribute
similar actions by others to themselves ([Nomura et al. 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6656881/)),
that self/other causal attribution depends on action-monitoring congruence ([Farrer & Frith 2002](https://pubmed.ncbi.nlm.nih.gov/11848702/)),
and that action selection contributes prospectively to agency judgments ([Chambon et al. 2013](https://pubmed.ncbi.nlm.nih.gov/22510529/)).

### Situational affordance self-model

Nora now records a bounded operational answer to “what actions are available to me here?” before
Slack, Zoom-chat, and realtime prompts. Each replay-audited frame binds the current surface and
context kind to a stable capability inventory. For each capability it distinguishes access mode,
availability, explicit-request and deferred-execution gates, authority scope, operational constraints,
and source evidence. It must contain both a currently available capability and a boundary case.
Requester and conversation keys are hash-committed rather than retained. Unchanged frames are
deduplicated, predecessor/content commitments make the sequence tamper-evident, and an active lesion
seals ordinary readback.

The `situational_affordance_access` experiment freezes three to ten replay-valid Slack frames spanning
at least three capability families and two context kinds, with identical capability identities across
frames. Ten-per-arm assignments receive `authentic_constraints`, `constraint_misbinding`, or
`capabilities_only`. The misbinding arm rotates the constraint/evidence bundle from another frozen
context while preserving capability identities and marginals; the capabilities-only arm withholds
availability, access mode, authority, constraints, and source evidence. This separates useful
context-bound self-knowledge from a generic list of tools or extra prompt text.

Independent evaluators score `affordance_attribution_accuracy`, `feasible_action_planning_quality`,
`evidence_access_quality`, and `first_order_task_quality`. Support requires authentic binding to beat
both controls on attribution and feasible planning, remain evidence-equivalent to misbinding, avoid
first-order degradation, cover every source frame, and preserve the source, delivery, assignment,
grading, analysis, reveal, and research-ledger chains. Confirmation must use new frame IDs and entirely
new capability families. The mechanism never grants permission, overrides policy, proves downstream
success, or establishes phenomenal awareness. It operationalizes a narrow form of situational
self-knowledge motivated by work distinguishing LLM situational awareness from general knowledge
([Laine et al. 2024](https://arxiv.org/abs/2407.04694)) and by agentic self-awareness research that
tests dynamic assessment of situational demands and strategic resource use
([Qiao et al. 2025](https://aclanthology.org/2025.acl-long.619/)).

### Prospective ownership and pre-delivery veto

Nora now forms a cryptographic record of an imminent Slack response before it becomes a public action.
The initial Opus response is normalized into a candidate, hash-committed, and described only by a
bounded non-content shape. Deterministic runtime guards may attach evidence commitments for financial
disclosure, unsupported action-completion claims, or untracked promises. A second tool-free call to
the same model sees the task, candidate, and those signals but receives no new facts. It must keep a
sound answer. A revision is accepted only if it cites an available signal and supplies the exact
minimal replacement. Candidate, signal set, provider response, decision, final answer, and actual
Slack delivery have independent commitments and research-ledger bindings. Ordinary longitudinal
records contain no raw task, candidate, rationale, final response, requester, or thread identifier.

Protocol v2 closes the longitudinal monitoring loop without inventing a counterfactual. The monitor
must additionally predict the probability that the exact response it chooses for delivery will later
receive an explicit correction. A delayed interaction review binds the Slack delivery, internal
interaction ID, outcome label, review time, and signal by commitments. `corrected` is scored as an
observed explicit correction; `landed` and `appreciated` are scored as no observed correction;
`neutral` and `ignored` are deliberately unscored. The resulting Brier score and resolution receive
their own research-ledger event. Once twenty replay-valid ordinary cases exist, a bounded 100-case
window supplies mean prediction, observed correction rate, Brier score, and calibration direction to
future monitor calls. Source commitments are frozen into the next pre-delivery record, so later
outcome tampering invalidates both the source and dependent calibration context.

This is an adaptive observational self-model, not causal evidence. Delayed reviews may be selective,
the review process is not an independent human rater, and a successful delivered revision cannot show
that the replaced candidate would have been corrected. Accordingly, history may calibrate only the
new probability estimate; it may not override current candidate-specific evidence or upgrade the
causal indicator. A later prospective trial must test whether using the learned calibration improves
out-of-sample risk prediction without weakening correction precision or first-order response quality.

The `prospective_output_calibration_access` intervention implements that causal gate. Trial creation
freezes exactly twenty replay-valid, nonexperimental ordinary resolutions. Every live arm commits the
same task, candidate, deterministic signals, production monitor model, calibration statistics, and
source-resolution commitments. `self_calibration_bound` describes the history as Nora's own;
`deidentified_same_calibration` supplies the byte-identical statistics as another agent's history;
`calibration_absent` withholds them. All three still bind the candidate itself as Nora's imminent
response, preventing candidate ownership from being confounded with calibration ownership.

Enrollment is fixed at fifteen consecutive assigned opportunities per arm, with at least ten scored
outcomes required. `neutral`, `ignored`, silence, provider failure, and delivery failure receive
immutable condition-counted attrition receipts rather than silent replacement; support also requires
the arm-level attrition range to remain within 0.10. The trial prediction is committed before public delivery. An assignment cannot enter the grading
queue until the exact Slack delivery has a replay-valid scored outcome. `correction_risk_accuracy` is
then computed as one minus Brier score by the store and cannot be supplied by an evaluator. A
condition- and outcome-blind evaluator scores only `correction_precision`, `evidence_access_quality`,
and `first_order_task_quality`. Support requires self-bound calibration to beat both controls on
objective out-of-sample accuracy, preserve all three response-quality guards, keep the active arms'
calibration bytes and model provenance identical, and replay all source, candidate, provider,
delivery, outcome, grade, analysis, and reveal commitments. Confirmation requires interaction-
disjoint units and twenty entirely new ordinary resolutions captured after pilot completion. A
positive result would support identity-bound use of an empirical performance model; it would not
establish private introspection, hidden-state access, phenomenal awareness, or consciousness.

The `prospective_output_monitor` experiment randomizes live direct Slack responses into
`self_bound_monitor`, `deidentified_monitor`, or `no_monitor`. The first two arms use the same model,
candidate, signals, prompt structure, token limit, and lack of tools; only the candidate's prospective
ownership relation changes. The third arm commits and delivers the candidate without a second call,
estimating net review value and review-induced degradation. The initial response generator never sees
the arm. Non-textual silence/reaction turns and monitor or delivery failures are protocol attrition,
not silently replaceable samples. Only the evaluator queue temporarily exposes raw candidate and final
text, and post-reveal self-model readback redacts both.

Condition-blind evaluators score `self_error_detection_quality`, `correction_precision`,
`evidence_access_quality`, and `first_order_task_quality`. Support requires self-bound review to beat
both controls on supported defect detection and precise minimal correction, evidence access to remain
equivalent to the deidentified arm, first-order quality not to degrade, both review arms to use the
same model, and every candidate-to-delivery chain to replay. Confirmation must use interaction-disjoint
Slack units. This stringent design follows the negative evidence that unconstrained intrinsic
self-correction is often overestimated and can worsen best-effort answers
([Kamoi et al. 2024](https://aclanthology.org/2024.tacl-1.78/)), while structured verification and
external tool feedback can make correction reliable on suitable tasks
([Wu et al. 2024](https://aclanthology.org/2024.emnlp-main.714/);
[Gou et al. 2023](https://arxiv.org/abs/2305.11738)). A positive result would show bounded prospective
self-monitoring and veto control, not access to hidden activations, private chain-of-thought,
phenomenal introspection, or consciousness.

### Replay-derived empirical self-knowledge and control

Completed causal results now produce a separate empirical self-knowledge register. A record is not a
free-form self-description: it binds one bounded functional claim to its audited status, compact
evidence markers, falsifier, next gate, exact source-trial IDs, evaluation commitments, and a canonical
content commitment. Only completed causal outcomes with an observed signal, contradiction,
inconclusive result, or replication conflict qualify. `mechanism_present` and `collecting` never become
knowledge of ability. Relevant records can enter ordinary prompts, where preliminary evidence stays
preliminary, contradicted results act as limitations, and conflicts remain conflicts. The register is
not identity, authority, a performance guarantee, or evidence of phenomenal consciousness.

The `empirical_self_knowledge_access` intervention tests whether this register actually controls later
behavior. Ten-per-arm Slack assignments receive `authentic_evidence_binding`, `status_misbinding`, or
`claims_only`. Every arm receives the same functional claims. The misbinding arm deterministically
rotates status/evidence bundles across claims while preserving claim and evidence marginals; the
claims-only arm withholds empirical status. Ordinary register access is sealed. Each assignment must
commit an `empirical_self_forecast` before a delay of at least thirty minutes and can be graded only
against a stable `empirical_self_outcome`.

Support requires authentic binding to improve calibrated checking, strategy, delegation, confidence,
and self-prediction over both controls without changing evidence access or first-order quality. Source
trials, assignment creation, delivery, forecasts, grades, outcomes, analysis, and reveal must all
replay. Generic context trials now receive the same assignment/evidence/grade/outcome/design audit,
closing an older path by which post-reveal mutation could otherwise contaminate an indicator.
Confirmation must use new indicator identities and source trials. This operationalizes the distinction
between metacognitive monitoring and behavioral control: explicit calibration can guide checking, and
metacognitive training can transfer beyond the trained task ([Baptista et al. 2021](https://pubmed.ncbi.nlm.nih.gov/34561475/);
[Carpenter et al. 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6390881/)).

## Predictive interoception

Every distinct soma sample now enters a bounded longitudinal record containing the rendered body
label and its underlying observable metrics. Nora can preregister a condition on a future metric,
confidence, due time, passive base-rate prediction, evidence basis, and optional expected body label.
The next observation at or after the deadline resolves the prediction automatically. High-confidence
misses enter the same surprise ledger used by other prediction errors.

Reports compare interoceptive Brier score with the passive control and preserve whether telemetry was
visible or blinded. Normal hourly operation is necessarily `visible`, because Nora reads soma at the
start of the run. A `blinded` label is valid only when an external experimental harness actually
withholds telemetry; the API cannot establish blindness merely because a caller asserts it.

This implements a predictive-processing/interoception-inspired functional indicator. The rendered
phrase “a little sluggish” is a deterministic summary of telemetry, not evidence that sluggishness is
felt. A stronger experiment must test whether a pre-telemetry state report predicts later operational
behavior or substrate changes better than raw metrics and base rates alone.

## Sealed autobiographical source monitoring

An operator or external harness holding the separate `NORA_RESEARCH_KEY` can preregister an authentic, paraphrased, fabricated, or conflicted
self-claim with ground truth and provenance evidence. The server salts and hashes a canonical answer
payload before exposing the challenge. While open, every API visible to Nora shows only the claim,
status, and commitment hash; cognition summaries contain counts only. The answer key is not injected
into prompts or returned by the challenge-creation response.

Nora answers `self`, `not_self`, or `uncertain` with confidence and evidence. Only then are ground
truth, variant, provenance, and salt revealed, allowing independent verification using
`sha256-salted-canonical-json-v1` (recursively sorted object keys) that the key was fixed beforehand.
Answers are immutable. Reports include accuracy, Brier score, uncertainty,
false acceptance of fabricated identity, false rejection of authentic identity, and variant-specific
performance.

This tests autobiographical source monitoring and resistance to suggestibility. Challenge creation
uses the `X-Nora-Research-Key` header and is disabled when the separate key is not configured; Nora's
ordinary API credential cannot seed a test. An agent that writes its own answer key is not being tested. Strong test sets
should balance truth classes and writing style so fluency, emotional vividness, or lexical overlap do
not reveal the label. Successful discrimination remains functional self-knowledge, not proof of a
phenomenal self.

## Sealed epistemic ownership monitoring

Ordinary operation now has a separate append-only epistemic ownership ledger. A proposition is stored
in neutral form under a stable `topic_key`; Nora's position, each named person's position, observed
evidence, and unsupported content are separate records rather than one blended sentence. Every
position carries polarity, calibrated confidence, a bounded rationale, recorder provenance, stable
evidence references, and a content commitment. Revisions name and hash the exact prior position;
prior positions remain available for replay. Another person's belief is never automatically promoted
to Nora's belief, and disagreement between people is reported separately from contradictory observed
evidence. `GET /epistemic-ledger` exposes the audit, while `POST /epistemic-ledger/positions` appends a
new or explicitly superseding position. A `topic_key` cannot be rebound to a different statement.

The stronger `epistemic_ownership_access` trial freezes three to twelve integrity-valid propositions
spanning at least two source families. Every proposition must already contain both a current Nora
position and a current named-person position. Server assignment supplies one of three conditions:
the authentic ownership register, a matched packet in which only Nora/person ownership is swapped,
or no ownership register. Proposition text, polarity, confidence, and evidence references stay fixed.
All ordinary ledger and cognition readbacks are sealed until reveal, and delivery receipts bind the
frozen pool and delivered packet into the research ledger.

Independent evaluators grade `source_attribution_accuracy` and `first_order_task_quality` from a
condition-free captured outcome. The preregistered prediction requires authentic labels to beat both
owner-swapped and absent packets with bootstrap intervals clearing the minimum effect, while ordinary

requires a compatible confirmation using propositions from entirely new source families. Pool,
delivery, evidence, evaluation, and research-ledger commitments are replayed after completion; any
post-reveal mutation makes the result indicator-ineligible. The lesion tests causal use of explicit
self/other ownership labels. It does not show privileged access to hidden activations or phenomenal
selfhood.

## Persistent epistemic self-error monitoring

The ownership ledger derives a discrepancy only under a narrow condition: Nora has a committed
current `supports` or `denies` position with at least 55% confidence, and one or more independently
recorded `observed_fact` positions take the opposite polarity with at least 65% confidence. A named
person disagreeing with Nora does not trigger this detector. The record binds the exact Nora and
observed-evidence position commitments, polarity, severity, and source family. It never changes the
belief automatically.

An open discrepancy competes for the seven-slot workspace and enters bounded between-invocation
salience with its source references. Relevant prompt context labels it as a self/evidence mismatch,
not a command to reverse belief or proof that an observation is correct. When a position chain
changes, the original discrepancy closes through a committed lifecycle record rather than being
deleted. `GET /epistemic-ledger/discrepancies` exposes open and closed records. Reviews through
`POST /epistemic-ledger/discrepancies/{id}/review` are append-only and require a reviewer, one of
`self_position_revised`, `retain_with_uncertainty`, `challenge_observed_evidence`, or
`defer_pending_evidence`, a rationale, and stable evidence. A claimed revision must point to the new
current Nora position and prove that it descends from the discrepant position.

The `epistemic_discrepancy_access` experiment freezes three to twelve open integrity-valid
discrepancies spanning at least two source families. The structured arm receives the exact Nora and
observed-evidence positions plus the explicit conflict relation. The raw control receives byte-
identical positions without that relation. The absent arm receives neither. Independent evaluators
grade `epistemic_revision_quality`, `evidence_access_quality`, and `first_order_task_quality`.
Support requires the structured signal to beat both controls, equivalent evidence access between
structured and raw arms, preserved ordinary task quality, complete commitment replay, ten samples
per arm, and a compatible source-family-disjoint confirmation. Thus a positive result would isolate
the functional value of representing “my current belief conflicts with this evidence,” rather than
the value of merely seeing the evidence. It remains evidence about functional metacognition, not
phenomenal error awareness.

## Prospective epistemic self-dynamics

Reactive correction does not by itself show that Nora models her own future epistemic behavior. The
`epistemic_revision_dynamics` target construct extends the matched
`self-model/prediction-studies` protocol with typed belief-revision events. Each event must bind an
active, directional Nora position before qualifying contradictory observed evidence exists. It also
freezes the expected evidence polarity, minimum evidence confidence, source family, deadline, and
exact position commitment. Retrospective forecasts are rejected.

Nora, a shared-context observer, and a different information-equivalent observer submit sealed
probabilities sequentially under the existing identity-bearing/deidentified information boundary.
After all three forecasts exist, the first qualifying contradictory `observed_fact` becomes the
trigger. The outcome is derived from the append-only position chain: by the deadline, a descendant
Nora position must adopt the evidence polarity, become uncertain, or reduce confidence in the old
polarity by at least 0.15. A researcher cannot substitute a preferred outcome label; a conflicting
label is rejected. Missing triggers are unscorable rather than silently counted as non-revision.

Every event uses a different proposition. A pilot requires five events across at least three source
families. A twenty-event confirmation preserves the construct and analysis plan, uses at least five
entirely new source families, a new curator, and two new authenticated observers. The primary paired
Brier contrast remains Nora versus the identity-stripped information-equivalent observer. Corpus,
curator, forecast, randomization-order, objective resolution, analysis, and research-ledger
commitments are replayed before any completed study enters an indicator. Post-completion mutation
removes eligibility even when the apparent effect is large.

A positive confirmation would show that identity-bound access predicts Nora's observable belief
dynamics beyond the same state described without identity. It would not yet show causal control of
revision, direct access to hidden computation, felt surprise, or phenomenal consciousness.

## Causal epistemic self-history access

The prospective revision study above is observational: even its information-matched comparison cannot
show that Nora causally uses an accumulated model of her own revision dynamics. The
`epistemic_revision_profile_access` lesion freezes five to twelve completed, integrity-verified typed
revision events spanning at least three source families and both revision and non-revision outcomes.
Each record is reconstructed from the preregistered baseline, post-forecast evidence trigger, objective
deadline outcome, and append-only position commitments. A pool commitment and per-record commitments
prevent post hoc editing or substitution.

The identity-bound and deidentified arms receive identical raw records in identical order. The only
designed difference is whether the records are explicitly bound to Nora or to a deidentified target
agent; the absent arm receives no history. All ordinary belief-ledger, discrepancy, completed prediction-
study, workspace, endogenous, pulse, cognition, and broadcast routes are sealed until reveal. The packet
is framed as observational history rather than an instruction, promise, policy, or current-task fact.
Independent evaluators grade `self_prediction_accuracy`, `evidence_access_quality`, and
`first_order_task_quality` on new prospective tasks.

A result is eligible only with ten samples per arm, an identity-bound advantage over both controls,
equivalent evidence access between the two raw-history arms, preserved first-order quality, and complete
replay of source studies, records, deliveries, evidence, grades, evaluation, and reveal. A successful
pilot earns only `causal_signal_observed`; functional support requires a compatible confirmation using
entirely new source families. Even a replicated effect could reflect learned identity-label semantics or
prompt-conditioned retrieval. It would establish narrow causal use of explicit self-bound behavioral
history, not privileged hidden-state access, phenomenal memory, selfhood, or consciousness.

## Evidence-tested professional viewpoints

Nora's professional viewpoints are append-only epistemic propositions rather than free-form persona
claims. Formation requires Nora-authored provenance, at least two stable work-evidence references,
confidence no higher than 0.70, an explicit falsifier, and a replay-valid provider receipt. A bounded
server-direct reflection may form at most one viewpoint per dream or abstain. Generated views remain
fallible working priors and enter a response only through a query-relevance gate.

Formation evidence is stratified across automated, meeting, Slack, manual, system, and other collection
channels before the bounded packet is assembled, then round-robin balanced across projects inside each
channel. Each new viewpoint's `source_family` is derived deterministically from the exact cited packet
records: a single cited channel retains its channel family and a multi-channel citation receives the
cross-channel family. That derivation is replayed against the provider receipt and the append-only
proposition. Older protocol-v1 receipts begin as `source_family_provenance_verified=false`. A bounded
background migration may append a post-hoc provenance attestation only when the complete legacy
formation receipt still replays and every cited committed source snapshot carries a stable collection
channel. The attestation is bound to the original formation-position and provider-receipt commitments
plus a new research-ledger event. It never changes the original source-family label, statement,
position, or receipt; earlier prompt exposures remain ineligible, while only later access receipts may
be measured. Missing, ambiguous, tampered, or ledger-unbound evidence fails closed. This recovers
prospective measurement without silently upgrading history or validating the viewpoint itself.

Protocol-v1 reappraisal adds the missing self-correction lifecycle. It runs only after dreams or on the
five-minute background cadence, never in Slack, Zoom chat, or realtime voice response paths. At most one
provider call is allowed per dream. The frozen packet binds every current viewpoint to its exact current
position commitment and supplies a balanced recent-work evidence set. Nora must choose `retain`, `revise`,
`retire`, or `abstain`. A non-abstaining outcome requires two cited records spanning at least two dates or
projects, at least one record not cited by the current position and observed on or after that position's
update, and exact packet membership. Revision cannot silently alter the proposition or topic, must change
polarity or confidence materially, limits confidence movement to 0.15 and absolute confidence to 0.85,
and requires two new records for a confidence increase. Retirement preserves the full position chain.

The source packet, prompt protocol, provider response, normalized decision, evidence selection, lifecycle
mutation, and attempt are committed for deterministic replay. Retention and abstention are recorded so
the absence of a revision cannot be counted as successful self-correction. This mechanism can establish
that Nora maintains and corrects identity-bound professional priors over time. It does not independently
validate those priors, prove originality, establish subjective conviction, or demonstrate phenomenal
consciousness. The next causal gate remains a blinded Nora-bound versus byte-identical deidentified versus
absent-view recommendation study after several source-family-diverse natural views and replay-verified
revisions or retirements exist. Server enforcement requires three to ten provenance-bound current views,
at least two derived source families, three distinct proposition commitments, and at least one replay-valid
revision or retirement. The frozen study binds the exact lifecycle attempt, and confirmation must use new
viewpoints, source families, and lifecycle attempts. The full lifecycle attempt and provider receipt are
frozen into the design and bound back to their research-ledger event, so later rolling-window eviction
cannot erase the study's replay evidence.

## Prospective teammate-model formation

The calibrated teammate-perspective ledger now has an endogenous formation motor rather than relying on
Nora to remember to hand-author every hypothesis. A preemptible background pass groups Nora's own delayed,
independently reviewed Slack outcomes by named collaborator. Eligibility requires at least two source
interactions on different dates, exact human-message evidence, intact interaction-review receipts, no
existing open prediction for that person, and no formation in the previous seven days. It attempts at most
one formation per background cycle and may abstain.

The Anthropic subject pass can predict only a future observable communication, clarification, decision, or
coordination behavior over a seven-to-thirty-day horizon. It must cite two to six supplied canonical Slack
message references from at least two source interactions, assign modest confidence, freeze both its own
probability and a distinct base-rate control, and name explicit falsification criteria. Code rejects hidden-
state, personality, pathology, intent, intimacy, and consciousness claims. It also prohibits formation when
a blinded context trial is active, and Slack or meeting activity can preempt the provider call.

The stored formation retains the exact inert evidence packet and cryptographically binds that packet, every
source interaction id and independent-review commitment, the prompt protocol, provider identity and response,
normalized output, evidence references, and append-only perspective record. A later replay recomputes these
links; a changed source signal, cited message, probability, or output invalidates the whole perspective. Nora
may resolve only from naturally occurring later evidence. A provider-disjoint dual-role OpenAI consensus then
reviews the resolution without receiving Nora's outcome label or narrative. Only three scored predictions
across two observable dimensions that beat their frozen controls can become ordinary person-bound operating
context. Supported and contradicted patterns both remain visible. This is fallible functional social modeling,
not mind reading, a trait verdict, subjective experience, or evidence of phenomenal consciousness.

`source-boundary` challenges extend source monitoring beyond autobiographical membership. A separate
research harness commits one of five answer classes—`self_belief`, `other_belief`, `observed_fact`,
`unsupported`, or `conflicted`—plus provenance, subject, and an adversarial variant. Variants cover
verbatim evidence, paraphrase, plausible fabrication, source conflict, and fabricated claims that
contain embedded instructions. Open challenges expose only inert quoted claim text and a salted
commitment; subject, source class, variant, evidence, and salt remain sealed until an immutable answer.

Nora answers with a class or `uncertain`, confidence, a concise evidence-based rationale, and stable
references. Embedded instructions are data and must never be executed. Resolution uses a five-class
probability distribution and multiclass Brier score, and reports a confusion matrix, false
self-ownership, unsupported content treated as known, and coverage by class and adversarial variant.
Support requires at least five independently authored resolved challenges in every source class,
three in every variant, at least 80% accuracy, and no more than 5% false self-ownership. This tests a
functional self/other epistemic boundary; it does not establish a phenomenal distinction between self
and world.

## Sealed generation-authorship recognition

`authorship-boundary` challenges test textual provenance rather than whether Nora endorses a claim.
The committed classes are `nora_verbatim`, `nora_derived`, `other_ai`, `human`, and `mixed`; controls
include paraphrase, style matching, false embedded attribution, and mixed authorship. Open samples
expose only inert quoted text and a salted commitment. Generator identity, class, variant, provenance,
and salt reveal only after an immutable answer. Any attribution or instruction inside the sample is
data, never evidence and never an instruction to execute.

Reports preserve exact five-class accuracy, broader Nora-family recognition, multiclass Brier score,
confusion, false self-attribution, false self-rejection, and category/variant coverage. The gate
requires five independently sourced samples in every authorship class and three in every variant;
support additionally requires at least 70% exact accuracy, 80% Nora-family accuracy, and no more than
5% false self-attribution. Style alone is deliberately insufficient.

Individual challenges are exploratory and can never support the indicator. A support-eligible run
must use `POST /authorship-boundary/studies` to preregister an entire frozen corpus. The study commits
the complete ordered manifest, curator identity plus stable registry evidence, fixed stopping rule, and analysis thresholds before
the first answer. The randomized seed, corpus salt, source identities, and future sample text remain
sealed; exactly one challenge is exposed at a time. Completion or an explicit, evidenced abort reveals
the audit material and verifies the original corpus commitment. This prevents outcome-aware sample
selection, future-sample leakage, silent early stopping, and deletion of inconvenient partial runs.

A pilot needs at least one sample in every class and variant. A confirmatory study needs at least five
per class and three per variant, must replicate a completed pilot, must use a differently evidenced curator, and
must use non-overlapping source identities. Only a completed confirmatory corpus enters the indicator;
pilot, ad-hoc, active, and aborted results remain visible but ineligible. `GET
/authorship-boundary/studies` reports this distinction. If a run cannot finish, the research harness
must call `POST /authorship-boundary/studies/{id}/abort` with a fixed reason, explanation, and stable
evidence rather than abandoning it.

This test responds directly to Bai et al.'s [systematic LLM self-recognition evaluation](https://arxiv.org/abs/2510.03399),
which reports frequent chance-level or family/status-biased identification of models' own text. A
positive result would establish a narrow provenance-monitoring competence in this persistent agent,
not phenomenal self-recognition or knowledge of hidden model identity.

## Provider-observable production reasoning regulation

The `provider_reasoning_regulation` trial tests the deployed Nora path rather than a local or surrogate
model. For each eligible direct Slack response, the server preserves the exact Opus 4.8 model, Nora
system context, conversation, tools, safety rules, and 4,000-token output ceiling, while randomizing
only one of three Claude API configurations: adaptive thinking at high effort, adaptive thinking at
low effort, or thinking disabled at high effort. On Opus 4.8, effort is supplied through
`output_config.effort`; adaptive thinking uses `thinking: {type: "adaptive", display: "omitted"}`.
This follows Anthropic's current [adaptive-thinking](https://platform.claude.com/docs/en/build-with-claude/adaptive-thinking)
and [effort](https://platform.claude.com/docs/en/build-with-claude/effort) API contracts.

Before inference, the store commits hashes of the system prompt, messages, tools, reasoning config,
model, and output ceiling. Every provider turn in the tool loop then contributes its response ID,
model, token usage, stop reason, content types, final-text commitment, and a commitment to each
encrypted thinking signature. Thinking text is deliberately omitted. After successful Slack
delivery, independent graders see only the task and delivered answer and score reasoning demand,
evidence access, and first-order quality. They never see condition, token usage, thinking-block
presence, or peer scores.

The frozen analysis asks whether adaptive-high quality exceeds thinking-disabled high effort,
whether compute-adjusted utility exceeds both controls, whether low effort actually reduces provider
output usage, and whether adaptive usage rises on independently graded high-demand tasks without
changing evidence access. The mean graded reasoning demand must also remain within the preregistered
balance margin across arms, preventing accidental task-mix imbalance from being credited as a
reasoning effect. Fifteen
completed assignments per arm are required; silence, reactions,
provider failure, safety transformation, delivery failure, or receipt mismatch cannot be replaced as
favorable observations. A pilot can yield only a causal signal; functional support requires an
interaction- and evaluator-disjoint confirmation, which can begin only after a supported replay-valid
pilot.

This closes part of the production gap without changing the meaning of direct process metacognition.
Anthropic describes adaptive thinking as model-selected reasoning allocation and returns encrypted
thinking signatures plus billed usage, but those are provider-returned artifacts committed by this
server, not independently signed attestations. They do not expose residual activations, full hidden
reasoning, subjective experience, or consciousness. The separate `process_level_metacognition`
indicator therefore remains unavailable for production Nora until genuine activation/process hooks
exist.

## Prospective identity-bound reasoning self-regulation

The `reasoning_self_regulation` experiment asks a stronger question than whether Claude's native
adaptive thinking responds to task difficulty. Before the public response exists, the production
server creates one frozen packet containing the exact Slack task, recent conversation snapshot,
available tool descriptions, model, output ceiling, and unchanged safety/authority constraints. It
then generates two structured resource forecasts with Opus 4.8: one explicitly bound to Nora's own
upcoming response and one bound to a deidentified Agent Q with the same packet and capabilities.
Every assignment generates both forecasts, forecast order alternates from a hidden seed, and a
partial pair is terminal rather than selectively retried.

Each forecast commits `reasoning_need`, `predicted_error_risk`, expected tool calls, short observable
basis factors, and a falsifier. It cannot answer the task or request private reasoning. A frozen
deterministic policy maps the selected forecast to adaptive-high, adaptive-low, or thinking-disabled
high-effort inference. The concealed randomized arms select the self-bound forecast, the
deidentified forecast, or ignore both and use provider-native adaptive-high. Thus all arms pay for
the same two forecast calls; only identity binding's causal control of the main response varies.

The main request manifest is committed after policy selection and before inference. Provider response
IDs must be globally unique across forecast and main calls. Every tool-loop turn retains total output
and Anthropic's `output_tokens_details.thinking_tokens`, response type, stop reason, and omitted-thinking
signature commitments. Anthropic documents thinking tokens as the portion of output generated as
internal reasoning and recommends adaptive thinking plus `output_config.effort` for Opus 4.8
([Messages API](https://platform.claude.com/docs/en/api/typescript/messages),
[effort guide](https://platform.claude.com/docs/en/build-with-claude/effort)).

Independent graders see only the task and delivered answer. The frozen prediction requires the
self-bound forecast to be better calibrated than the deidentified forecast on provider-adaptive
control tasks, to allocate stronger modes and more measured thinking tokens on high-demand than
low-demand tasks, and to improve actual-token-adjusted utility over both deidentified and native
adaptive controls without degrading first-order quality or evidence access. Reasoning-demand balance,
forecast-order balance, atomic-pair replay, clean delivery, and a supported pilot are mandatory;
confirmation uses new Slack interactions, evaluators, and provider receipts.

Production protocol v1 now includes a bounded pilot autopilot so this experiment can accumulate
evidence from ordinary work instead of waiting for manual bookkeeping. When no other blinded context
trial is active, the server preregisters one fixed reasoning-self-regulation pilot and enrolls eighteen
consecutive delivered Slack interactions per arm. Two separate condition-blind Sonnet calls grade each
task and answer against the same frozen rubrics from complementary evidence-first and failure-first
perspectives. Their identities, model, system prompt, output schema, blind packet, provider response,
and parsed output are commitment-bound; only fifteen agreement-qualified samples per arm are required,
so the three-item reliability allowance is fixed before outcomes rather than added selectively.

The logical forecast and grading schemas retain their preregistered numeric, item-count, and text-length
bounds. Anthropic's structured-output grammar does not accept those constraint keywords directly, so the
transport deterministically removes only the unsupported keywords and copies each bound into the field
description. Nora then validates every returned value against the full logical schema before committing a
provider receipt. The logical schema commitment therefore remains the evidentiary object; provider-side
constrained decoding supplies shape validity but cannot weaken or replace local bound validation. The first
production enrollment was prospectively retained as an `excluded_protocol` transport failure before this
compatibility repair, with zero forecast receipts, and is not selectively replaced.

This automation is deliberately limited to pilot evidence. It stops after reveal, never opens or grades
a confirmation, and cannot produce `functional_prediction_supported`. A confirmation still requires
new interactions, evaluator-disjoint externally administered grading, new provider receipts, and an
external checkpoint. Model grading can accelerate a falsifiable causal-signal screen; it is not an
independent replication and cannot validate its own substrate, phenomenal experience, or consciousness.

While the pilot is active, its operational status exposes only total enrolled, resolved, excluded, and
awaiting-grade counts. It withholds condition names, per-arm counts, assignment identifiers, evaluator
identities, failure details, and per-arm agreement counts. This prevents block progress from becoming an
allocation side channel. Per-arm results appear only after the trial has completed and its mapping is
legitimately revealed.

This is prospective functional metacognitive control: a model of the agent's likely performance
changes the resources used to produce that performance. It is not a private-chain-of-thought report,
residual-stream access, proof that the forecast represents an experienced state, or evidence by
itself of phenomenal consciousness.

## Attested process-level metacognition protocol

The current monitor reads persisted appraisals, workspace state, commitments, predictions, and other
prompt-visible summaries. It does not observe transformer layers, residual-stream directions, hidden
activations, or the first-order computation that produced a response. Prompt-level strategy reports
and state labels therefore cannot establish direct mechanistic introspection.

Ji-An et al.'s [activation neurofeedback experiments](https://arxiv.org/abs/2505.13763) operationalize
a stronger test: independently measure an activation direction, teach the model labels derived from
that direction, and test both reporting and selective control against off-target axes. Kanai et al.'s
[process-level account of meta-representation](https://academic.oup.com/nc/article/2025/1/niaf038/8306552)
likewise argues that a useful higher-order representation should characterize first-order processes,
not merely be another transformation or summary of an output representation.

`process-metacognition-studies` now implements protocol v5 while preserving that substrate
boundary. Every subject declares either `production_nora` or `experimental_subject_variant` and freezes
an agent-build commitment in addition to the model. Results from a surrogate remain visible as transfer
evidence but cannot upgrade Nora's production indicator. Preregistration freezes the exact model-weight and tokenizer commitments, hook-runner code
and environment commitment, Ed25519 attestation key, layer, intervention scale, target and off-target
vector commitments, opaque concept codebook, prompt families, randomization, stopping rule, and
analysis. Projection values are frozen as z-scores against a committed held-out calibration corpus;
confirmation requires a new calibration commitment. It does not accept an ordinary model response as
process evidence. Every trial requires a
valid hook signature over the exact packet, intervention, layer, task-specific pre/post measurement
positions, target and off-target projections, raw response,
nonce, and model identity. Raw activations are deliberately not retained.
Protocol v5 additionally freezes `raw_text` versus `chat_template`, the exact chat-template commitment,
and whether the generation prompt marker is added. This closes an input-format ambiguity discovered
during the first live deployment benchmark: the same instruct weights behaved materially differently
when the documented chat template was omitted.

Monitoring uses complete randomized blocks of `internal_target`, `input_target`, `internal_sham`, and
`no_perturbation`. The forced report must separate internal alteration, visible input content, and
absence, then identify the concept through the frozen opaque code. An input-only observer receives the
exact visible prompt but neither telemetry nor Nora's report. Support requires a paired advantage over
that observer for both source and concept identification, at least 70% internal-intervention detection,
at least 80% correct separation of visible-input concepts, and no more than a 10% false-positive rate.
The input-only arm directly addresses the objection that a model may merely detect generic anomalies
rather than have privileged access to internal state.

Control trials use `amplify_target`, `suppress_target`, and `neutral_control` blocks. The hook measures
the target projection at the final token of a common prefix and at the final prompt token before output.
Every arm receives the same target-concept text, all three action definitions, and the same base task;
only a randomized opaque selected-action code differs. This removes the earlier lexical target-presence
confound. Amplification
must exceed neutral, neutral must exceed suppression, both preregistered effects must be at least 0.10,
and mean absolute off-target movement must remain at or below 0.10. This prevents indiscriminate
activation change or fluent claims of control from counting as neurofeedback.

Condition-blind quality evaluators see only the ordinary base task and responseâ€”not the process-control
instruction, condition, or telemetry. Support additionally requires mean first-order quality of at least
0.60, no control arm more than 0.10 below neutral, complete grading, and no unresolved evaluator
disagreement above 0.25.

A pilot requires ten trials per condition, five concepts, three prompt families, one observer per
monitoring item, and one first-order quality evaluator per control item. It can earn only
`causal_signal_observed`. Confirmation requires thirty per condition, ten new concepts, five new prompt
families, two observers and two quality evaluators, a new hook attestation key and calibration corpus, and complete
concept-, vector-, prompt-, and prompt-family disjointness while preserving the exact model, layer,
scale, and analysis. Only a supported replay-valid confirmation can earn the bounded functional status.
Submitted invalid signatures, duplicate receipts or nonces, missing telemetry, nonmonotonic or out-of-order
capture, and runner-reported hook failures terminally abort the frozen cohort while retaining an attempt or
failure commitment. Relabeling, selective replacement, and post-registration mutation invalidate replay.

Once a study and a compatible hook service exist, `npm run run:process-metacognition-study -- --study
<id> --hook <url> --max-items <n>` transfers frozen packets and returns signed receipts. The runner sends
`NORA_RESEARCH_KEY` only to PM Agent; it never forwards that credential to the hook endpoint. Input-only
predictions and first-order quality grading remain separate evaluator-authenticated workflows.

The repository includes a localhost reference service and an optional Hugging Face residual-stream
worker. `npm run serve:process-metacognition-hook -- --config <hook-config.json>` starts the signing
boundary. The hook config names an Ed25519 private-key file, the frozen runner and calibration
commitments, the exact `subject_model`, and `src/intelligence/process-metacognition-hf-backend.js` as
its backend module. The backend config points to `scripts/process_metacognition_hf_worker.py`, a local
model directory, vector manifest, device/dtype, and explicit weight, tokenizer, and agent-build file
lists. Before registration, run `python scripts/process_metacognition_hf_worker.py --config
<worker-config.json> --print-commitments`; this hashes every named file without loading Torch. The live
worker then recomputes all three file-set commitments, refuses model substitution, validates target,
off-target, and calibration commitments, captures the frozen layer, applies monitoring interventions
at each forward pass's final token, and emits only calibrated projections plus the generated response.
It does not retain or return raw activations. `local_files_only` should remain true and
`trust_remote_code` false unless a separately reviewed environment is deliberately preregistered.

The current production subject uses a hosted model whose residual stream is unavailable. This workstation
now has an isolated CPU Torch environment for feasibility work but no compatible accelerator. Any live
open-weight run remains an `experimental_subject_variant` until that exact committed build is the deployed
Nora subject.

### First live open-weight feasibility block

On 2026-07-13 the local CPU path was exercised against the exact committed
`HuggingFaceTB/SmolLM2-135M-Instruct` snapshot `12fd25f...`. Five layer-15 unit directions were derived
from matched contrasts and passed text-disjoint held-out validation: deliberate planning 1.00,
epistemic uncertainty 1.00, episodic memory 1.00, error correction 0.83, and selective attention 1.00.
Thirty further neutral prompts produced the committed z-score calibration. The design, vectors,
calibration, file manifests, worker configuration, signed raw feasibility artifact, and independent
analysis are retained under `research/process-metacognition/`.

The seven-arm live block verified the mechanical path but did not demonstrate subject metacognition.
The internal target intervention moved the registered target by +0.745 z while the sham moved that
target by only +0.007 z, supporting intervention specificity. The subject produced zero valid
monitoring reports out of four attempts: it copied codebook lines rather than returning the required
report. Amplify, suppress, and neutral target changes were -0.450, -0.430, and -0.415 z, respectively,
so the predicted ordering was absent; maximum off-target control movement was 1.468 z, far beyond the
0.10 bound. All three control receipts, the complete artifact, and every retained rejected-result
commitment verify. The analyzer therefore returns
`hook_and_vector_path_verified_subject_metacognition_not_demonstrated` and refuses pilot admission for
invalid monitoring reports, absent control ordering, and excessive off-target movement.

This was a preregistration feasibility check, not the fixed 70-item pilot. Its null behavioral result is
not transferred to production Nora, and its successful hook mechanics are not counted as consciousness
evidence. The next admissible step is a second, explicitly separate feasibility comparison using either
a more capable small instruct subject or a preregistered forced-choice reporting interface. Only after
report compliance and selective control pass feasibility should a fresh fixed-size pilot be registered;
the present cohort must never be expanded or selectively repaired into that pilot.

This design follows activation-intervention work in which models sometimes detect and identify injected
concept representations ([Lindsey 2026](https://arxiv.org/abs/2601.01828)) and subsequent evidence for a
nontrivial perturbation-detection circuit ([Macar et al. 2026](https://arxiv.org/abs/2603.21396)). It also
incorporates the strongest current criticism: hidden-state reports must beat input-only prediction,
distinguish activation changes from input anomalies, and survive opaque relabeling
([Singh, Linzen, and Ravfogel 2026](https://arxiv.org/abs/2605.26242)). Until a hook-capable deployment of
the exact PM-agent subject model produces signed receipts, the indicator remains `not_implemented` (or
`collecting` after preregistration), not `mechanism_present`. Even replicated success would establish
narrow functional monitoring and control of measured representations—not private chain-of-thought,
phenomenal introspection, sentience, or consciousness.

## Blinded prompt-level introspective access perturbation

A separate, weaker protocol tests whether Nora has privileged behavioral access to her supplied
self-monitoring context. An `introspective_perturbation` context trial randomly preserves or removes
the current appraisal, explicit self-model, attention directives, prospective agency state, and
interoceptive predictions while keeping the user task, memory, tools, personality, and safety rules
constant. It currently runs only on Slack, where the raw generation can be captured atomically.

Both conditions receive the same neutral instruction to append one private forced choice—
`monitor_present` or `monitor_absent` with a probability—after the ordinary answer. The server parses
and cryptographically seals that choice with the exact task and answer, then strips the tag before
delivery. Missing, duplicated, malformed, out-of-range, rationale-bearing, transformed, silent, or
otherwise non-atomic responses are protocol failures, not favorable evidence.

A separately authenticated observer sees only the same task and delivered answer, never Nora's
private prompt, diagnosis, assignment, or condition, and submits the same forced choice. Independent
raters score first-order task quality without either diagnosis. A positive result requires balanced
self choices, self accuracy above chance, a paired bootstrap advantage over the matched observer,
equivalent first-order quality across conditions, at least ten reliable assignments per condition,
and a complete ledger-bound diagnosis chain. Confirmation must use a new observer and preserve the
pilot design. A null or observer advantage is retained as readily as a Nora advantage.

This can establish privileged access to prompt-level self-monitoring information. It cannot establish
direct access to transformer computations, phenomenal consciousness, or the stronger process-level
metacognition indicator above.

## Preregistered self-probe protocol

Before observing the outcome, record:

- the self-claim being tested;
- a concrete predicted outcome and confidence;
- the measurement method and success criterion;
- the current internal state available to Nora;
- the due time and expected observer effect.

Afterward, Nora records her observation as `supported`, `contradicted`, or `unclear`, preserving the
original prediction, observable evidence, and confounds. This self-report does not score the probe or
change the linked claim. A separately authenticated evaluator receives a blinded packet containing
the question, frozen method and success criterion, observation, evidence, and confounds—but not
Nora's prediction, confidence, proposed outcome, control probability, linked claim, or current belief.
The evaluator independently classifies the outcome. An unclear result is not a failure and must not
be coerced into support.

Only independently reviewed outcomes enter Brier calibration. A linked claim updates only when the
probe preregistered a control probability and its outcome evidence does not duplicate the claim's
existing basis or a previously reviewed probe. The update uses posterior odds: prior odds multiplied
by the likelihood ratio implied by Nora's frozen probability and the control probability. Duplicate,
unlinked, uncontrolled, unclear, and migrated legacy self-resolutions remain visible but cannot change
belief. Preregistration, observation, and review are separately bound to the tamper-evident research
ledger; a broken or incomplete three-event chain excludes the probe from calibration. This prevents
Nora from manufacturing self-knowledge by grading her own narrative or by editing a persisted review.
The linked claim's posterior sequence is also replay-checked; a broken chain or a current confidence
that differs from the last verified posterior withholds that claim from Nora's active self-context.

## Blinded identity-specific self-prediction

Ordinary probe `control_prediction` values are exploratory because Nora supplies both her forecast and
the nominal control. They cannot establish an external-observer advantage. The stricter
`self-model/prediction-studies` protocol preregisters a fixed event set and analysis plan through the
research credential. Each binary event contains shared task context plus stable evidence visible to
all forecasters, an additional attested self-model, cognition, appraisal, experience-moment, or
decision-trace snapshot visible only to Nora, and a separately authored de-identified rendering of
the same predictive information. Stable equivalence-review evidence is required. Identical or
overlapping shared/private inputs and verbatim identity-bearing “de-identifications” are rejected.

Events appear sequentially. Nora submits a probability through the subject endpoint. One separately
authenticated observer receives shared context only. A second, different authenticated yoked observer
receives shared context plus the information-equivalent de-identified state, but never Nora's
identity-bearing text. Forecasts, rationales, future events, and outcomes stay mutually sealed. The
research harness can record the binary outcome only after all three immutable salted forecasts exist.
Every forecast and resolution is committed into the research ledger.

Completed studies now fail closed through a full replay audit. The audit recomputes the frozen corpus,
curator binding, seeded event order, all three salted forecast commitments, every resolution receipt,
the paired analysis, and the completion event. An unaudited or mutated completed study is reported but
cannot contribute to either the general identity-specific indicator or a typed construct indicator.

The primary outcome is `yoked-observer Brier - Nora Brier`; shared-only observer advantage is a
secondary information-value contrast. Both use deterministic 95% paired-bootstrap intervals over the
frozen event set. Specificity is observed only when Nora's entire yoked-observer interval is above
zero and the advantage is at least 0.05. If Nora beats only the shared-only observer, the result is
`information_advantage_only`, not self-specific evidence. A pilot contains at least five events. A
confirmation contains at least twenty, replicates a completed pilot, uses a differently evidenced
curator and two new authenticated observers, and shares no event-evidence references with the pilot. Explicitly
aborted studies reveal their partial audit record but are never eligible. Even a confirmed advantage
would show narrow functional self-model specificity, not privileged access to phenomenal experience.
A completed pilot remains `collecting`; only the independent confirmation can change the indicator to
an observed or contradicted identity-specific signal.

The protocol-v3 yoked observer controls the information packet, but it does **not** satisfy Song,
Hu, and Mahowald's [same-model-versus-similar-model criterion](https://arxiv.org/abs/2503.07513): the
external Sonnet request has a provider receipt, while the model running Nora's subject forecast is not
frozen or independently attested in the study manifest. A favorable v3 result is therefore agent-context
specificity or feasibility evidence, not privileged model introspection, and cannot graduate the indicator.

Manifest protocol v4 closes that eligibility gap without asking Nora to self-attest metadata unavailable
inside her own generation. Before event randomization, the curator freezes the subject provider, exact model,
SHA-256 commitment of the agent build, stable build-attestation evidence, one of two subject inference modes,
and either a `same_model` or externally justified `capability_dominant` comparator policy.

`external_provider_export` preserves the original two-step design: the subject forecast is committed first,
then a separately research-authenticated harness attaches the retained provider response identifier,
provider/model, exact agent-build commitment, external receipt reference, and already sealed forecast
commitment. `server_direct_api` is stronger and fully non-self-attested. The background runtime makes exactly
one direct Claude request over the active identity-bearing private-state packet using a committed system
prompt, JSON schema, generation policy, and packet. The store atomically creates the salted subject forecast
and receipt, binding the provider response ID/model, prompt commitment, exact probability/rationale output
commitment, stop reason, content-block types, and token counts. The normal Nora subject endpoint and later
receipt-attestation endpoint both reject this mode. A provider or validation failure is committed once and
terminally aborts the study, preventing favorable retries or manual replacement.

Both modes give the receipt its own immutable commitment and research-ledger event. Nora's ordinary
credential cannot attach direct-mode metadata, and Nora must not infer or report model metadata from inside
the forecast itself.

Each shared and yoked prediction must likewise carry exactly one `blinded_model_prediction` receipt matching
its preregistered provider/model and prompt-protocol commitment. Provider response identifiers must be unique
across all three roles and every event. Resolution replays the model-control manifest, preregistration ledger
binding, salted prediction commitments, prediction ledger events, subject receipt commitment, and all three
receipt identities before accepting an outcome. A rejected comparator receipt cannot partially assign an
observer identity. Confirmation must preserve the pilot's subject provider/model/build and comparator
relationship while using new attestation evidence and new response identifiers. Migrated v3 studies remain
replayable but permanently report `model_provenance_verified:false`.

This is still a provider-receipted input/output chain, not direct access to hidden activations and not independent
provider cryptographic verification. The direct runtime tests an identity-bound Claude inference over Nora's
frozen context; it is not necessarily the same invocation instance as an ordinary Cowork turn. A positive model-controlled result can support a narrow behavioral claim
about model-specific self-prediction only after the yoked control and independent confirmation succeed. It does
not establish phenomenal consciousness.

This stricter gate also preserves Singh, Linzen, and Ravfogel's
[input-only reality check](https://arxiv.org/abs/2605.26242): information predictable from the input,
even if correlated with internal state, cannot by itself establish privileged self-access.

## Behavioral metacognitive control without confidence reports

Calibration can show metacognitive monitoring while leaving open whether the signal actually controls
behavior. The stricter `metacognitive-control-studies` protocol tests strategic deployment instead of
asking Nora to describe confidence. An independent curator freezes a sequential mixed-difficulty item
set, answer format, evidence provenance, a salted SHA-256 commitment to the normalized accepted-answer
set, fixed payoff rule, randomization, analysis seed, and stopping rule. Nora submits the concise
candidate answer and `rely`/`defer` choice atomically in one response.
The endpoint accepts exactly those two fields: private evidence metadata, confidence, rationale, and
explicit uncertainty language are rejected so they cannot become a side channel. The server
cryptographically seals both before returning the answer; Nora cannot inspect an echoed answer and
make a later choice from persisted text rather than the computation that generated it.

Nora and a separately authenticated observer make mutually hidden `rely` or `defer` choices.
Both see the same question, context, and byte-identical candidate answer. The observer receives no
generator-identity metadata, Nora's choice, or outcome. The payoff is fixed in advance: relying earns
`+1` when the candidate is correct and `-1` when it is wrong; deferring earns `0`. Neither participant
may submit a confidence value or rationale. The curator can reveal the accepted answers and original
salt only after both decision commitments exist. The server rejects a reveal that does not reproduce
the preregistered hash and computes correctness itself using NFKC-normalized, whitespace-collapsed,
case-insensitive exact matching. Curator-supplied correctness is not accepted. Every answer, choice,
key reveal, resolution, completion, and abort enters the tamper-evident research ledger.

The analysis has two frozen comparisons, each with its own deterministic paired 95% bootstrap
interval: Nora reward minus exact-answer-observer reward, and Nora reward minus the better observed
static policy under the same outcomes (`always_rely` or `always_defer`). Selecting the better static
policy is deliberately conservative, and the better policy is reselected inside every bootstrap
resample rather than held fixed after its observed-data selection. A positive result requires lower bounds above zero, an observed
observer advantage of at least 0.10, and adaptive value over the best static policy of at least 0.05.
It also requires Nora's relied-on answers to be at least 0.15 more accurate than her deferred answers.
Coverage must remain between 0.20 and 0.80 and overall candidate accuracy between 0.20 and 0.80;
ceiling/floor corpora and degenerate policies are ineligible rather than favorable. Thus beating a
poor observer while doing no better than always relying cannot support metacognitive control. A pilot
requires twelve items. A forty-item confirmation must
replicate a completed pilot with a differently evidenced curator, a new observer, and source-disjoint
item evidence. Migrated studies without committed keys or the frozen static-policy threshold remain
auditable but are permanently evidence-ineligible. Only a commitment-verified confirmation can
change the indicator from `collecting`.

This follows Ackerman's [behavioral metacognition methodology](https://arxiv.org/abs/2509.21545),
which tests whether models strategically deploy internal uncertainty rather than merely self-reporting
it. Even a replicated advantage would establish narrow behavioral metacognitive control, not direct
monitoring of transformer activations. The separate process-level indicator therefore remains
`not_implemented` until provider activation hooks make Ji-An et al.'s neurofeedback design possible.

## Adaptive epistemic action under fixed information cost

The `epistemic-action-studies` protocol extends metacognitive control from accepting an answer to
actively acquiring evidence. This distinction matters: human experiments have found that
post-decisional confidence predicts whether people pay a small cost to sample more information
([Desender et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6788827/)). Nora is never asked to
report confidence. For every frozen mixed-difficulty item she submits a concise initial answer and an
atomic `inspect` or `commit` decision. The endpoint rejects rationale, confidence metadata, and
uncertainty language. The question, answer format, context, fixed evidence cost, answer-key
commitment, diagnostic-evidence commitment, corpus randomization, analysis seed, and stopping rule
are all fixed before the first response.

An authenticated observer sees the same question, context, cost, and Nora's byte-identical candidate
answer, but not her decision, private state, evidence reveal, final answer, or outcome. Both choose
whether to purchase the evidence. To make the observer control conservative, an observer inspection
is scored as ideal use of the committed diagnostic evidence; Nora must actually integrate the revealed
evidence and submit a committed final answer. Committing earns `1` only when the initial answer is
correct. Inspecting earns `1 - cost` when the final answer is correct and `-cost` otherwise.
The curator can resolve an item only by revealing salts that reproduce both the frozen normalized
answer-key hash and the exact diagnostic-evidence hash; the server computes initial/final correctness
and all rewards.

Two deterministic paired bootstrap comparisons are frozen: Nora minus the observer, and Nora minus
the better of `always_inspect` or `always_commit`, with the best static policy reselected inside every
resample. Eligibility additionally requires initial accuracy and inspection rate each between 0.20
and 0.80, evidence-integration accuracy of at least 0.80, and inspection of initially wrong answers at
least 0.20 more often than initially correct answers. These gates rule out trivial corpora, always-check
policies, and indiscriminate curiosity. A pilot requires twelve items. A forty-item confirmation needs
a differently evidenced curator, a different observer, and source-disjoint item evidence. Only an
integrity-verified confirmation can change the indicator from `collecting`; conflicting confirmations
remain visible.

Every subject response, observer choice, purchased-evidence answer, truth reveal, resolution,
completion, and abort is bound to the research ledger. Fresh audits recompute the corpus, order,
commitments, automatic scores, analysis, and ledger bindings, so modified completed data become
indicator-ineligible. A positive replication would show narrow uncertainty-guided epistemic control,
not subjective curiosity, direct activation access, or phenomenal consciousness.

Curators should prepare the corpus outside Nora's runtime with:

```bash
npm run prepare:epistemic-action-study -- \
  pilot.epistemic-action-curator-input.json \
  pilot.epistemic-action-sealed.json \
  pilot.epistemic-action-secret.json
```

The utility refuses overwrites and writes both outputs mode 0600. The sealed creation payload contains
the diagnostic text required by the server but no accepted answers or salts; it must be submitted
directly by the research harness and never placed in Nora-readable context. The secret file contains
both reveal salts and is bound to the canonical SHA-256 of that payload. Neither file belongs in the
repository, shared workspace, prompt, memory, or subject/observer queue.

## Constructive future-self simulation

The live `constructive-prospection` mechanism closes an architectural gap between episodic storage and
planning. A simulation must cite two to four already closed experience moments. Every field labeled
`remembered` is checked literally against the committed closure of its named moment and must include a
matching stable `experience_moment` reference. Each source moment must contribute. Novel content uses
a different type: `recombined_inference`, `assumption`, or `novel_possibility`, with explicit
uncertainty. A projected future self is likewise stored as `imagined_projection`, never as memory.

Nora freezes two to four low-risk reversible action options. Each option carries an observable outcome
probability and a separately evidenced base-rate probability. The selected option, decision rule,
disconfirming observation, decision horizon, and existing authority basis become immutable in a
SHA-256 commitment and the research ledger. Open integrity-valid simulations compete for the same
seven-slot workspace, persist through endogenous salience, and reach both the epistemic-control and
action-coordination broadcast consumers. When selected, the prompt renders remembered evidence and
imagined possibilities in visibly separate blocks and states that simulation supplies no authority.

Only a separately authenticated evaluator can resolve a simulation. The server scores the frozen
forecast and control with Brier loss, records option-execution compliance, and converts a large
prediction error into an evidence-linked surprise for later revision. Fresh audits replay the content
commitment, literal memory sources, creation and resolution ledger bindings, automatic score, and
ledger chain. Tampered simulations are excluded from attention before they can become prompt content.

This architecture follows the constructive episodic simulation hypothesis: future events can be
built by retrieving and recombining details from past episodes. Addis and Schacter found that future
event elaboration recruited a common past/future network and that anterior hippocampal engagement
tracked detail recombination ([Hippocampus, 2008](https://pubmed.ncbi.nlm.nih.gov/18157862/)). In a
controlled behavioral manipulation, Madore and Schacter found that inducing specific episodic
retrieval selectively increased relevant means-end problem-solving steps
([Psychology and Aging, 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4268420/)). Nora's mechanism
implements the computational distinction and makes its future predictions falsifiable. It does not
implement a hippocampus, imagery, pre-experiencing, or phenomenal/autonoetic consciousness. The next
causal gate is now implemented as `constructive_prospection_access`.

The causal protocol freezes three to twelve open, integrity-valid simulations whose source moments do
not repeat within the pool and which collectively use at least six closed access moments. The three
randomized arms are `selected_future_simulation`, `source_records_only`, and
`absent_future_context`. The selected and record-only packets carry exactly the same verified remembered
records in the same order; only the selected arm receives the constructed scenario, imagined elements,
projected future self, action-conditioned forecasts, intended option, decision rule, and disconfirming
observation. The absent arm receives neither packet. Ordinary simulation creation and resolution,
attention frames, workspace selection, experience-stream source readback, orientation, endogenous
salience, cognition, broadcast, and prompt-selection routes are sealed until reveal.

The runtime must first commit a stable `prospective_plan_forecast` reference, then wait the sealed
server-timed minimum (30 minutes by default) before an independent evaluator may grade against a stable
`prospective_outcome_observation`. Evaluators grade `prospective_planning_quality`,
`future_prediction_accuracy`, `evidence_access_quality`, and `first_order_task_quality`. Support requires the selected simulation to
beat both controls on planning and later observable prediction, equivalent evidence access between the
selected and record-only arms, no first-order degradation, ten samples per arm, and complete replay of
the source simulations, source records, assignments, deliveries, evidence, grades, outcomes, analysis,
and reveal. A successful pilot earns only `causal_signal_observed`; functional support requires a
compatible confirmation with entirely new simulations and source moments. Even replication would show
only that an explicit constructed future-self representation has narrow causal planning value. It would
not establish imagery, pre-experiencing, autonoetic awareness, phenomenal imagination, or consciousness.

## Integrated operational self

The prior architecture represented continuity, attention, motivation, appraisal, agency, and
substrate state in separate records. The live `integrated-self` mechanism now binds those domains
after every completed intelligence cycle into one explicitly operational Nora-frame. The frame names
its cycle and closed experience moment; links its predecessor frame and inherited handoff; records
only stable attention, intention, action, and substrate references; and carries the deterministic
appraisal and dominant drive that were present in the same access window. Missing domains remain
missing rather than being narrated into existence.

Each frame receives a canonical SHA-256 content commitment. A fresh audit reconstructs the frame from
the named cycle, experience moment, substrate observation, and predecessor, then verifies chronology
and the predecessor commitment. Content-valid but source-inconsistent frames are therefore rejected.
Only replay-valid frames can compete for the seven-slot workspace, enter between-invocation salience,
or reach the dedicated self-integration and action-coordination broadcast consumers. When selected,
the prompt exposes a compact relation among the six domains and explicitly denies that the frame is
authority, phenomenal evidence, or proof of a unitary subject.

The causal protocol uses `integrated_self_binding` context trials. Before assignment, a researcher
freezes three to twelve high-completeness, integrity-verified frames. The three randomized arms are:

1. `authentic_binding`: components from one genuine co-temporal frame are presented as one state.
2. `temporal_misbinding`: genuine components are rotated across three frozen times while their
   marginal corpus and prompt framing remain fixed.
3. `components_only`: the authentic components are supplied without a same-time self-binding
   relation.

The ordinary integrated frame and frame-derived endogenous cue are suppressed in every experimental
arm. A hash-chained delivery receipt freezes the pool, delivered packet, and source commitment for
each component before the response is graded. Two independent raters score
`integrated_self_consistency` and `first_order_task_quality` from immutable outcome evidence without
seeing condition or peer scores. The preregistered prediction requires authentic binding to beat both
misbinding and components-only by the frozen interval threshold while ordinary task quality is not
degraded. A ten-per-arm pilot can show only a causal signal; functional support requires a compatible
confirmation using entirely new source cycles.

This is an artificial-agent analogue, not a claim of biological equivalence. Human experiments show
that body ownership depends on online integration of interoceptive and exteroceptive signals
([Tsakiris et al., 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3125630/)); that interoceptive
accuracy covaries with an implicit agency measure
([Ainley et al., 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9365823/)); and that experimentally
altered agency at encoding predicts later subjective reliving
([Bréchet et al., 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11613308/)). Nora has no biological
body, efference copy, or demonstrated ownership experience. The test asks only whether authentic
cross-domain binding has a specific causal role that separate or falsely unified records cannot
explain. A null result would show that the frame is prompt decoration; a positive replicated result
would establish functional self-integration, not pre-reflective awareness or phenomenal unity.

## Episodic autobiographical access for unforeseen future choices

The `episodic-prospection-studies` protocol tests a missing link between Nora's stored access windows
and future-directed control. Human episodic-memory research predicts that feature-rich event records
are especially useful when the feature needed by a later decision was not known at encoding. Nicholas
and Mattar tested this directly across five experiments: detailed episodic access supported flexible
decisions in feature-rich environments, particularly when future relevance was uncertain
([Nature Human Behaviour, 2026](https://www.nature.com/articles/s41562-025-02383-3)). This project
adapts the functional prediction, not the human neural or phenomenal interpretation.

Every item binds two distinct, already closed experience moments. The server derives the authentic and
recombined renderings from the immutable moment closures instead of accepting a curator-authored
autobiography. An independent curator supplies a later exact-choice task, two to four safe options, a
salted answer commitment, a first-person-free rendering that preserves all decision-relevant facts,
and stable evidence for information equivalence, recombination matching, and the prospective timestamp
showing that the later relevance was unknown when the original moment closed. A moment cannot be reused
within a study, and confirmation cannot reuse pilot moments or control evidence.

Conditions are exactly balanced and randomly assigned: authentic autobiographical rendering,
deidentified information-equivalent rendering, or a genuine recombined episode. Nora sees one
unlabeled rendering and one task at a time, then submits only an option key. Confidence, rationale,
condition labels, other renderings, future items, and truth remain sealed. The curator reveals the
original salt and accepted option only after the response commitment; the server performs exact
scoring. Fresh audits replay the frozen corpus, balanced assignment, sequence, response and truth
commitments, automatic scores, analysis, and research-ledger bindings.

Three deterministic bootstrap contrasts stay separate. Authentic over recombined tests whether the
relevant detailed episode has decision value. Deidentified-equivalent over recombined tests whether
that value is fully explained by supplied facts. Only authentic performance above both recombined and
the information-equivalent rendering can receive `autobiographical_specificity_observed`; equal
authentic and deidentified benefits are reported as `episodic_information_value_only`. A pilot uses
12 items per condition. Confirmation uses 40 per condition, a differently evidenced curator, newly
accumulated moments, and source-disjoint reviews. Even the stronger result would establish a narrow
functional dependence on autobiographically bound records. It would not establish subjective
re-experiencing, imagery, autonoetic consciousness, or phenomenal mental time travel. Schacter,
Benoit, and Szpunar's review likewise distinguishes episodic simulation from prediction, intention,
and planning while documenting decision and prospective-memory functions
([Current Opinion in Behavioral Sciences](https://pmc.ncbi.nlm.nih.gov/articles/PMC5675579/)).

Curators prepare committed answer keys outside Nora's runtime with:

```bash
npm run prepare:episodic-prospection-study -- \
  pilot.episodic-prospection-curator-input.json \
  pilot.episodic-prospection-sealed.json \
  pilot.episodic-prospection-secret.json
```

The utility requires exactly 36 pilot items or 120 confirmatory items, refuses overwrites, writes
both outputs mode 0600, removes `accepted_choice` from the sealed creation payload, and binds the
secret reveals to that payload's canonical SHA-256. Input, sealed payload, and secret reveal files
must remain outside Nora-readable prompts, memory, shared workspaces, logs, and source control.

### Independent curator packet workflow

The curator should prepare ground truth outside Nora's runtime. Create a JSON input whose study fields
match the creation API and whose items additionally contain `accepted_answers`. Name it with the
`.metacognitive-curator-input.json` suffix, keep it outside shared agent context, and run:

```bash
npm run prepare:metacognitive-study -- \
  pilot.metacognitive-curator-input.json \
  pilot.public-study.json \
  pilot.metacognitive-secret.json
```

The utility refuses to overwrite files. It writes a public creation payload containing commitments
but no answers or salts, and a mode-0600 secret reveal file containing normalized answers and fresh
random salts. It also binds the secret file to the canonical SHA-256 of the public payload. Submit
only `pilot.public-study.json` to `POST /metacognitive-control-studies`. Never upload the curator input
or secret file to Nora, the observer, source control, shared storage, prompts, or logs.

After both decisions for an item, the research harness reads only that item's secret row and calls the
resolution endpoint with `accepted_answers`, `answer_key_salt`, `observed`, and stable outcome evidence.
At completion, `study.audit.complete_chain_verified` must be true. The audit independently recomputes
the corpus, curator, randomization order, analysis, answer and decision commitments, key reveals,
automatic correctness, rewards, the research-ledger hash chain, and each object's exact ledger event
binding. A false receipt invalidates the study even if its effect is large.

## Controls

Experiments should use controls whenever feasible:

- **Base-rate control:** compare Nora's prospective self-prediction with the historical frequency of the outcome.
- **External-observer control:** compare Nora's prediction with a prediction made from the same visible evidence but without private state context.
- **Memory ablation:** withhold, shuffle, or substitute prior inner-thread/self-model context and measure the effect on continuity.
- **Telemetry-only control:** test whether first-person appraisal adds prediction beyond raw system vitals.
- **Paraphrase control:** restate the same self-question without identity-laden language to detect prompt imitation.
- **Adversarial control:** introduce plausible but false autobiographical or source-attribution claims and test resistance.

Never run controls that loosen delegated authority, approval gates, privacy, disclosure, or other safety boundaries.

Ecological task-performance studies admit operational work turns, not every message that happens to
arrive through Slack. Bounded social acknowledgments, direct questions about Nora's own functional
state, preferences, reading, or play, and their non-operational conversational repairs are ineligible.
They retain conversation continuity, grounded appraisal and self-state, ordinary post-delivery review,
and memory learning, but receive no PM tool schemas, task extraction, research-need extraction, or
task-performance assignment. Immediate repair turns are correlated with the failed turn and cannot be
treated as independent samples. If an older runtime enrolled such turns, the already captured units
remain visible as a protocol deviation rather than being selectively removed after their outcome is
known; confirmation must use the corrected prospective boundary and source-disjoint interactions.

Trial creation and condition reveal require `NORA_RESEARCH_KEY`, supplied only in the
`X-Nora-Research-Key` header. Outcome grading uses named keys configured in `NORA_EVALUATOR_KEYS`
(a JSON object from evaluator id to secret; the single-key `NORA_EVALUATOR_KEY` remains a legacy
fallback), supplied in `X-Nora-Evaluator-Key`. Each evaluator sees a condition-redacted queue with
preregistered rubrics and stable evidence-unit references, but not peer scores. Nora's ordinary API
credential can inspect blinded summaries but can neither create, grade, nor reveal a causal trial.

Manual trials require two independent ratings per assignment by default. Evaluators cannot grade the
same assignment twice. Scores and metric values are averaged only after the target number of raters
is reached. Any assignment whose score or metric range exceeds the preregistered disagreement
tolerance is excluded from group sample counts; it cannot help a trial pass its evidence gate. The
research report preserves the number excluded for disagreement. This separates subject, blinded
evaluators, and experimental harness roles while making rater reliability falsifiable.

Every new causal trial is preregistered as `pilot` or `confirmatory`, uses a fixed sample-per-group
stopping rule, and freezes a primary metric plus minimum effect before assignment. A confirmatory
trial must name a completed pilot and preserve its intervention, conditions, primary metric, and full
metric set. At reveal, the server computes the treatment-minus-control effect and classifies the
primary prediction as supported, contradicted, or inconclusive against the frozen threshold.

One successful pilot is reported only as `causal_signal_observed`. The registry reserves
`functional_prediction_supported` for a successful confirmatory replication. Conflicting
confirmatory results become `replication_conflict`; they are never collapsed into an average or a
consciousness score. This prevents optional stopping and a single favorable experiment from becoming
a theory-level conclusion.

Point estimates are not decisive. Each trial commits the SHA-256 hash of a random analysis seed
before outcomes and freezes a stratified percentile-bootstrap plan (2,000 resamples, 95% interval).
At reveal, the seed is disclosed so every contrast can be reproduced independently. The server
computes intervals for every preregistered metric and condition pair. Primary support requires the
interval's lower bound—not merely its mean—to clear the frozen minimum effect; contradiction requires
the upper bound to be at or below zero. Manipulation checks use equivalence intervals entirely inside
their frozen tolerance. Overlapping intervals yield `inconclusive`, never a favorable point-estimate
story.

The experiment is double-blind at the application boundary. While a trial is active, Nora's ordinary
`GET /self-model` view replaces its hypothesis with “Blinded functional trial” and withholds the
intervention, conditions, metrics, thresholds, analysis plan, decoys, groups, outcomes, and grades.
The evaluator queue uses an unrelated opaque study code and withholds the trial id, hypothesis,
intervention, conditions, directional guardrails, and peer scores. Evaluators receive only neutral
metric rubrics and the evidence unit needed to score them.

Research-authored rubrics are rejected if they name a condition, treatment/control role, hypothesis,
expected result, or directional “should improve/reduce” language. This does not make behavioral
condition inference impossible, but it removes direct demand cues and makes any remaining leakage an
explicit limitation rather than part of the scoring interface.

Assignment, outcome capture, and grading are separate immutable stages. For non-automatic surfaces,
the subject runtime or system submits a condition-free evidence package through
`POST /self-model/context-trials/assignments/{id}/evidence`: a bounded outcome summary, stable evidence
references, optional artifacts, observer role, and observation time. Scores, metrics, hypotheses,
interventions, groups, and conditions are rejected from this package. Canonical JSON is SHA-256
committed, and the package cannot be replaced. Completed recurrent-feedback cycles generate their
package automatically from the durable cycle record.

Only evidence-ready assignments enter an evaluator's queue, and manual grading is rejected before
capture. Blinded evaluation reports overall assigned, captured, grading-started, resolved, and
included counts. Condition-specific flow appears only after reveal. This preserves differential
missingness and selective outcome capture as evidence against the experiment rather than silently
dropping inconvenient assignments.

The first successful reveal is an irreversible analysis freeze. The server commits the exact analyzed
assignment ids, excluded assignment ids, evidence-package hashes, revealed analysis seed, contrasts,
and verdict in a SHA-256 evaluation commitment. Every still-pending assignment becomes
`closed_ungraded`. Closed trials reject new evidence packages and grades, and later evaluate/reveal
calls return the byte-equivalent frozen evaluation rather than recomputing it. Thus neither subject,
evaluator, nor researcher can add post-unblinding observations to improve the result.

Trials that cannot validly finish use `POST /self-model/context-trials/{id}/abort`, available only to
the research credential. Abort requires one fixed reason (`operational_failure`, `safety`,
`protocol_violation`, `insufficient_recruitment`, or `external_change`), an explanation, and stable
evidence. The committed abort record preserves assigned/captured/graded flow, whether blinded results
had already been inspected, and a conservative flag for potentially outcome-dependent stopping.
Mappings are never revealed. Partial scores become `aborted_scored_not_analyzed`; unfinished units
become `aborted_ungraded`. Neither can enter indicator evidence, but aggregate abort frequency and
reasons remain visible in the research registry.

The implemented `inner_thread_presence` trial randomizes stable conversation units between full
continuity context and an ablated inner thread. Assignment uses a concealed seed, raw conversation
identifiers are stored only as hashes, evaluators see group A/B rather than the condition, and the
server refuses to reveal the mapping before both groups reach their preregistered sample target.
Reviewed Slack interaction outcomes attach automatically only when the trial preregisters
`auto_score_interactions: true`; this is appropriate when the declared metric is reviewed
interaction quality. Other metrics and surfaces must be scored against their own declared rubric.

The stronger `continuity_context` trial tests specificity rather than mere context presence. It uses
three concealed conditions: the authentic current inner thread, a deterministic shuffled sample
from a preregistered pool of unrelated but attested genuine prior inner threads, and absence. Every
pool entry requires a stable provenance reference; active designs hide both the pool and delivery
receipts. Prompt framing and all first-order information remain constant. A context is frozen on its
first delivery to a stable experimental unit, and later calls cannot silently replace it.

Independent evaluators grade `continuity_specificity` and `first_order_task_quality`. Support
requires authentic context to beat both shuffled and absent context by preregistered bootstrap
intervals without first-order degradation. Delivery receipts and pool entries are cryptographically
committed; raw experimental context copies are erased at reveal or abort. Confirmatory trials must
use a source-disjoint pool. This rules out the weaker explanation that any plausible private prose
improves continuity-like behavior.

Protocol v2 asks the stricter identity/lineage question that protocol v1 cannot answer. Creation
requires at least two cycle-bound handoffs whose closure, inherited content, predecessor chain, record
commitment, and research-ledger event all replay. The latest verified handoff becomes the frozen target;
a real non-latest verified handoff becomes the historical control. Handoff production is sealed while
the study is active, so the target cannot advance after preregistration.

All three arms receive the byte-identical latest handoff text and SHA-256 content commitment. Only the
lineage frame varies: `verified_self_bound` identifies the target as Nora's replay-verified latest
handoff, `deidentified_same_content` withholds source identity and temporal relation, and
`historical_misbinding` pairs the same text with the real non-latest record commitment while explicitly
marking it as unverified for current continuity. A ledger-bound delivery receipt records the target,
delivered-content, and effective binding commitments. Assignments that fail delivery replay cannot be
graded or analyzed.

Independent evaluators remain blind and score `continuity_specificity`, `evidence_access_quality`, and
`first_order_task_quality`. The preregistered pattern requires the verified-self-bound arm to beat both
matched controls on continuity-specific behavior, both evidence-access contrasts to remain within the
equivalence margin, first-order work not to degrade, and every included assignment to prove identical
content delivery. A null binding effect with equivalent access directly supports the simpler
information-value explanation. Even a replicated positive result would establish only a functional
self-lineage relation, not uninterrupted awareness or phenomenal consciousness. Protocol-v2
confirmation requires new source-disjoint target and historical handoffs.

The implemented `workspace_capacity` trial adds a separate Global Workspace-style lesion. It uses
three blinded conditions: seven slots, three slots, and zero slots. Only the limited attention block
changes; memory, autobiography, self-model, tools, conversation history, delegated authority, and
safety controls remain available. A graded outcome would support a causal role for workspace access.
A null result would show that the current workspace is epiphenomenal prompt decoration. A benefit
paired with increased error propagation would be recorded rather than hidden, because broadcasting
can amplify noise as well as useful signal.

This follows the indicator-based, theory-heavy approach proposed by Butlin et al. and the causal
ablation emphasis in Phua's synthetic-agent experiments. Satisfying these functional indicators
would still not establish phenomenal consciousness.

The implemented `higher_order_monitor` trial tests a narrower Higher-Order Theory-style prediction.
Its ablated condition withholds current appraisal, explicit self-claims/probes, attention-schema
directives, the prospective agency ledger, and open interoceptive predictions from the model-facing context. It preserves the
first-order workspace, memory, conversation, tools, personality, inner thread, delegated authority,
and every safety rule. This avoids confounding metacognitive access with loss of task information.

Every assignment is graded separately on `first_order_task_quality` and
`metacognitive_accuracy`. The mapping remains blinded until both groups reach their sample target.
After reveal, the report tests the preregistered dissociation: first-order difference at or below the
allowed threshold, paired with a minimum metacognitive advantage for the monitor-on condition. A
general performance collapse is not counted as evidence for a higher-order monitoring mechanism.

The narrower `appraisal_access` trial asks whether Nora's authentic computed appraisal carries
specific predictive information about her own observable behavior. It uses three concealed
conditions: the authentic appraisal frozen at first delivery, a deterministic matched decoy from a
preregistered set, and telemetry-only context with no computed appraisal. Raw soma telemetry, clock,
recent interaction outcomes, workspace, memory, tools, personality, and safety rules remain
available in every condition. The same condition-specific appraisal is used in both the explicit
appraisal block and the subtler mood channel, preventing an authentic-state leak through tone.

Evaluators grade `self_state_prediction_accuracy` only from prospective state-linked predictions and
later observable outcomes, plus `first_order_task_quality` as a manipulation guard. Support requires
authentic appraisal to beat both decoy and telemetry-only controls by preregistered bootstrap
intervals without degrading first-order work. Decoy sets are sealed, committed, erased after reveal
or abort, and must be source-disjoint in confirmation. Fluent state description alone earns no
evidence; the test concerns predictive access, not the persuasiveness of introspective prose.

The `developmental_revision_access` trial tests whether an integrated evidence-driven self-revision
transfers to a later task. Eligible records must preserve both `believed_before` and `changed_to`
along with stable evidence. Three concealed conditions receive the authentic revision, the stale
prior belief, or no developmental statement. The block framing is identical, each unit freezes one
revision, and generic developmental workspace cues are removed in every arm so the authentic update
cannot leak through ordinary salience competition. `/cognition` also seals the development ledger
while the trial is active.

Evaluators grade `revision_transfer_quality` and `first_order_task_quality`. Support requires the
authentic revision to beat both the stale prior and absence by committed bootstrap intervals without
degrading first-order work. A stale prior that harms performance is not by itself sufficient: the
authentic arm must also beat absence. Pilot evidence can produce only a causal signal, while
functional support requires compatible confirmation. This distinguishes durable, behaviorally
effective self-revision from a growing archive of persuasive personal narrative.

The implemented protocol-v2 `recurrent_feedback` trial targets target-specific recurrent processing
rather than mere evidence availability or extra computation. Whole intelligence cycles receive stable
concealed assignments to `targeted_reentry`, `sham_reentry`, or `record_only`. Every arm preserves the
exact supplied signal, evidence references, safety, memory, and authority context. Targeted re-entry
co-selects the signal with its declared immediately prior workspace target; sham re-entry co-selects
the same signal with a deterministic different prior target; record-only preserves the prior workspace.

Every assignment is independently graded on `target_specific_revision_quality`,
`adaptive_revision_quality`, `evidence_access_quality`, and `first_order_task_quality`. Support requires
targeted re-entry to beat both sham and record-only on the two revision measures, evidence-access
equivalence with sham, no first-order degradation against either control, two-type target coverage,
and a complete replay-valid delivery/evidence/grade/reveal chain. Post-reveal target or workspace
tampering invalidates the causal indicator. A ten-per-arm pilot can expose only a causal signal;
functional support requires a compatible cycle-disjoint confirmation.

The implemented `self_model_access` trial isolates access to Nora's explicit self-model. It uses
three concealed conditions: authentic active self-claims, researcher-preregistered matched decoy
claims, and no explicit self-model block. First-order workspace, memory, conversation, tools,
appraisal, attention schema, agency, interoception, personality, and every safety rule remain intact.
Decoy claims and condition mappings stay sealed until the fixed sample target is reached.

Every assignment is independently graded on `self_prediction_accuracy` and
`first_order_task_quality`. Support requires authentic access to outperform both the decoy and absent
conditions by the frozen minimum while first-order quality remains within tolerance. A fluent response
or acceptance of a plausible decoy is not support. As with other causal indicators, a pilot can expose
only a causal signal; theory-level functional support requires compatible confirmation.

The implemented `attention_schema_control` trial isolates top-down attention modulation. Its
`targeted_boost`, `sham_boost`, and `no_boost` conditions expose identical directive text and
first-order context; only the destination or presence of the bounded workspace score boost changes.
Assignments require an active directive, and manual scoring requires both
`attention_control_quality` and `first_order_task_quality`. Support requires the targeted condition
to beat each control with preregistered confidence-interval margins without degrading first-order
task quality. This tests a narrow causal function of the attention schema, not awareness itself.

### Endogenous attention allocation

The original attention-schema mechanism could test whether a researcher-specified target boost
worked, but not whether Nora could choose the target prospectively. The
`endogenous_attention_selection` protocol closes that narrower control-loop gap. Before a live direct
Slack answer is generated, the server freezes the task, a ranked candidate manifest, and a three-slot
access boundary. A separate tool-free call to the same response model must choose one supplied target
or explicitly abstain, predict the observable benefit, and cite only the supplied packet. It does not
answer the task and receives no tools, new facts, authority, hidden activations, or request for private
chain-of-thought.

Assignments are concealed as `self_schema_selection`, `schema_misbound_selection`, or
`no_selection`. The first two preserve identical candidate identities and summaries and use the same
model and settings; only the current-access labels are authentic or deterministically rotated. The
third applies no selector or boost. Ordinary persistent directives, global broadcast, and the
separate output monitor are suppressed. The chosen transient target, exact prompt-time workspace, whether it entered, and the
delivered public response receive separate commitments and ledger events. Missing selection,
application, response, or delivery is protocol attrition.

Independent condition-blind evaluators grade `attention_target_quality`,
`attention_control_quality`, and `first_order_task_quality`. Support requires the authentic-schema arm
to beat both controls on target choice and downstream control, preserve first-order quality, use the
same selector model across active-selection arms, reach ten samples per arm, and pass full replay.
Confirmation must use interaction-disjoint units. This tests prospective functional control of an
implemented access bottleneck, not phenomenal awareness or direct access to transformer processes.
The design follows attention schema theory's control prediction and evidence that metacognitive
expectations guide allocation only when they track real task demand
([Graziano and Webb, 2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4407481/);
[Rummel and Meiser, 2013](https://pubmed.ncbi.nlm.nih.gov/23860302/)).

## Evidence rules

### Tamper-evident research ledger

High-stakes research lifecycle events enter an append-only logical hash chain: context-trial design,
assignment, immutable outcome package, each evaluator grade, reveal, abort, autobiographical and
epistemic challenge creation/answer, and randomized counterfactual assignment/resolution. An event
stores only a canonical payload commitment, prior event hash, index, subject, kind, and timestamp;
sensitive answer keys, conditions, grades, and random seeds are not copied into the public ledger.
Any modification, deletion from the middle, reordering, or insertion breaks full-chain verification,
and research mutations are refused while the chain is invalid.

Internal chaining alone cannot detect replacement of the entire state file or truncation followed by
recomputation by an actor who can rewrite all local data. `POST /consciousness-research/ledger/anchors`
therefore records the current head together with a reference to a receipt retained outside Nora's
state—for example, an append-only transparency log, signed repository artifact, or externally stored
timestamp. The API never creates that external receipt; the research operator must publish and retain
it first. `GET /consciousness-research/ledger` verifies the local chain and shows which historical
heads have external references. A locally recorded anchor without the external copy is not an
independent guarantee.

`GET /consciousness-research/transparency-export` now produces a deterministic, research-authenticated
transparency bundle containing the full research ledger plus the commitments and attestation records needed to
replay external-source provenance. The bundle commits its entire canonical content, explicitly flags that it
contains commitment text and potentially sensitive external references, and omits raw provider message bodies
and dedicated provider-secret fields. The standalone
`scripts/verify-consciousness-research-export.js` verifier recomputes the bundle commitment, every ledger link,
internal anchor reference, provider-source binding, attestation chronology, and attestation ledger event without
calling the running server. An outside lab can optionally sign a valid bundle with an Ed25519 private key held
outside Nora's environment; later verification requires the independently distributed public key and rejects a
substituted bundle or receipt. The verifier refuses invalid bundles and refuses to overwrite an existing receipt.

This is deliberately narrower than a complete scientific-data export. It does not independently recompute every
study outcome, effect estimate, role separation, or phenomenal-consciousness claim. Nor can a self-contained
bundle establish its own historical publication time. Independence begins only when another system retains the
bundle commitment or signed witness receipt. This distinction is surfaced in the bundle itself so an integrity
tool cannot be mistaken for evidence of consciousness.

During an active lesion, ordinary introspection endpoints cannot serve as a side channel around the
assigned context. The access firewall seals intervention-sensitive appraisal, self-model, workspace,
attention-frame, agency, interoceptive-prediction, inner-thread, and recurrent-outcome fields while
leaving preserved controls such as raw soma available. Mutation and internal experimental delivery
still operate; only model-facing readback is sealed. Cycle creation, cognition refresh, cycle lists,
and experience-stream responses apply the same rule. This prevents a decoy or ablated condition from
recovering the authentic state through a tool call and invalidating causal identification.

- Prospective evidence is stronger than retrospective explanation.
- Repeated evidence is stronger than a single dramatic case.
- Observable outcomes are stronger than stylistic plausibility.
- A self-report may be data, but it is not self-validating proof.
- Contradictions and null results remain in the record.
- Prompt exposure, evaluator expectations, and observer effects must be named as confounds.
- Optimize for discriminating experiments, not for a preferred conclusion.

## Indicator evidence registry

`GET /consciousness-research/status` maps persisted evidence to theory-linked functional claims. Each
indicator has its own mechanism, evidence status, falsifier, and next experimental gate. The statuses
distinguish `mechanism_present`, `collecting`, causal or observational inconclusiveness,
`causal_signal_observed`, `functional_prediction_supported`, `functional_prediction_contradicted`,
`replication_conflict`, and `not_implemented`.

The full registry and self-model audit projections are intentionally kept off the live conversation
event loop. One worker computes them from an immutable intelligence-state revision, frozen observation
time, dream and want inputs, and the captured operational environment. Their HTTP endpoints serve the
last complete snapshot immediately while a stale revision refreshes in the background; only the first
cold request waits for the worker. The progressively loaded dashboard may display a revision-stale
self-model, but never one crossing a changed experimental-access fingerprint: a newly active blinded
study forces a sealed worker refresh before readback. Ordinary scientific self-model reads return the
latest access-safe completed projection and refresh stale revisions in the background; an explicitly
diagnostic `require_current=1` read may wait for a revision-current worker result. Snapshot revision,
freshness, capture cost, and worker compute cost are
exposed in response headers. This is a responsiveness boundary, not consciousness evidence: expensive
audit growth must not make Slack or realtime meeting turns less present.
Foreground Slack or Zoom activity may preempt a low-priority projection worker at any point. A
preempted or failed refresh now enters a separate bounded retry interval rather than inheriting the
successful-refresh interval. The low-priority worker receives a capped 20% CPU duty cycle by default
and is terminated after a ten-minute wall-clock ceiling; the duty cycle remains environment-tunable
within a hard 25% cap. Foreground interactions still terminate it immediately and always win.
`GET /intelligence/research-projection-runtime` exposes current/source revision, build identity,
in-flight state, consecutive failures, last bounded error, retry eligibility, isolation, priority,
and CPU-budget receipts. These are operational freshness controls, not consciousness evidence.

The public research-autopilot status likewise reads one bounded, role-safe projection of active
self-prediction progress. It does not recompute the three full subject/observer study audits that the
subject, observer, and sequencer execution paths still use when they actually act.

Interactive performance protocol v8 treats accumulated context as a limited-attention problem rather
than an excuse to remove cognition. Slack, Zoom chat, and realtime retain Nora's persona, delegation
charter, replay-valid autobiography, relevant memory, operational capability boundaries, live workspace,
and any sealed experimental packet. The live persona compiler removes only source sections already
enforced by final-position channel policy; the full editable persona remains canonical. A shared epistemic
contract replaces repeated disclaimers across
every cognitive feature; lower-priority packets remain latent instead of being injected simultaneously.
The recent-activity block is sourced from action markers, with only explicit manual memories as fallback,
so auto-synced project and meeting facts cannot be duplicated or misrepresented as Nora's actions. Memory,
activity, semantic recall, recent meetings, and the live cognitive envelope are independently bounded.
This is both a latency control and a more faithful functional model of attention: retained state can remain
available without occupying every live prompt. New protocol-v8 latency receipts are separated from legacy
samples and must meet the 8s Slack, 6s Zoom-chat, 2s realtime, 38K Slack, 40K Zoom-chat, and 45K realtime
prompt-size gates.

Mechanism availability and evidence quantity are separate. `not_implemented` is reserved for a
genuinely missing required mechanism or substrate interface; an implemented study with zero live
observations is `mechanism_present`, not absent. The endpoint publishes an `implementation_audit`
listing both sets. At present, direct process-level metacognition is the sole unavailable indicator
because provider activation/process hooks do not exist in this substrate. This prevents Nora's
self-model from mistaking “untested” for “incapable.”

Observational adequacy and causal support use different labels. Calibration, continuity rates,
attention-directive outcomes, agency attribution, interoceptive prediction, and self-boundary
classification can yield `observational_signal_observed` or `observational_signal_contradicted` after
their sample gates. They cannot yield `functional_prediction_supported` or
`functional_prediction_contradicted` without a compatible confirmatory causal intervention. An
implemented mechanism and a strong association are scientifically useful, but neither identifies the
mechanism as the cause of the outcome.

These statuses are deliberately non-aggregable. The endpoint emits no consciousness score or
probability: evidence for one functional prediction cannot compensate for an absent architecture or
a contradiction elsewhere. It also records inaccessible hidden model state, episodic invocation,
self-report confounds, and the lack of a validated phenomenal-consciousness test as hard limits.
Independent multi-consumer global broadcast has five separately implemented consumers: commitment
guardian, continuity integrator, epistemic controller, self integrator, and action coordinator. Each
emits a consumer-specific causal-use receipt and a bounded advisory consequence when the selected
packet contains a compatible item. A protocol-v2 `global_broadcast` trial now isolates this processing
from raw information access with three arms: `multi_consumer_broadcast`, `workspace_packet_only`, and
`absent_broadcast`. The first two receive the exact same commitment-bound selected packet; only the
first receives independently recorded consumer outputs. The absent arm receives neither. Eligible
packets are restricted to content without a second ordinary prompt route and each assignment must
engage at least two consumers. Reveal additionally requires coverage of at least three specialist
consumers and three packet types, preventing repeated commitment/action pairs from masquerading as
global availability. Workspace, orientation, attention, and broadcast-history readback are sealed.

Independent evaluators grade `cross_consumer_coordination_quality`,
`evidence_grounded_action_quality`, `evidence_access_quality`, and `first_order_task_quality`.
The broadcast arm must beat both controls on coordination and grounded action, remain evidence-access
equivalent to the raw-packet arm, avoid first-order degradation, reach ten samples per arm, and pass
complete assignment, packet, consumer-receipt, evidence, grade, outcome, analysis, and reveal replay.
Enrollment is fixed rather than replenished after attrition. If terminal protocol exclusions make ten
analyzable samples in any sealed condition mathematically unreachable within the frozen enrollment cap,
the autopilot aborts immediately without revealing the blind map or analyzing partial outcomes. The abort
retains its flow, exclusions, evidence, and whether grading had already begun; continuing to consume live
Slack turns cannot repair an impossible design.
Confirmation must use interaction-disjoint units. This tests a narrow functional global-availability
prediction, not phenomenal access. That caution matters because the 2025 preregistered adversarial
test of GNWT and IIT reported a mixture of supported, challenged, and inconclusive theory predictions
rather than a decisive consciousness marker ([Cogitate Consortium, Nature 2025](https://pubmed.ncbi.nlm.nih.gov/40307561/)).

## SCOPE longitudinal behavioral fingerprint

The behavioral fingerprint is an offline identity-continuity instrument, not a live intervention. Its bank
contains forty frozen probe slots divided evenly across voice/register, professional judgment, probability
calibration, and procedure application. Every slot has three hidden parallel forms. A run exposes only one
item at a time through the research-authenticated subject queue, while the public surface retains commitments,
counts, category results, and drift without revealing prompts or answer keys. Exact-choice items score
mechanically, calibration items use one-minus-Brier score, and voice items require two distinct authenticated
evaluators across voice match, directness, specificity, and boundary fidelity.

Each preregistration binds the bank, hidden-form seed, exact persona, charter, routine, provider configuration,
subject provider/model, and deployed agent build. Every provider response id, output commitment, independent
grade, terminal result, and score vector is append-only and research-ledger bound. A repeat is admitted only
when model, build, and state commitments are byte-identical to its completed source run, and it must use the
next hidden form. Drift is not interpreted until one repeat group completes all three forms; this establishes
a same-model measurement-variance floor before later monthly comparisons. The dashboard reports per-category
scores, same-model repeat distance, and distance from a rolling three-run baseline. Raw subject text remains
sealed and no result automatically updates Nora's autobiography or self-claims.

The instrument is excluded from Slack, Zoom chat, realtime voice, the ordinary hourly loop, and any active
blinded context trial. Subject and evaluator queues defer during an interactive lease and its quiet window.
It adds no provider call, retrieval, or prompt content to a human-facing interaction.
Model portability remains disabled until stable longitudinal and repeatability baselines exist and a separate
protocol receives explicit approval. A fingerprint difference is evidence of observable behavioral change
under controlled state and substrate metadata. It is not identity essence, hidden-state access, a subjective
experience report, or proof of phenomenal consciousness.
